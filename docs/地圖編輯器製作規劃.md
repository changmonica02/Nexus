# Nexus — 地圖編輯器製作規劃

> 本文件整理已確認的功能與架構方向；尚待決定或技術驗證的事項列於文末。

## 1. 地圖類型與用途

| 類型 | 核心形式 | 編輯與顯示 |
| --- | --- | --- |
| **六角地圖** | 可持續擴張的六邊形格網，適合自由建構地理與世界觀 | 平面編輯、平面檢視 |
| **星球地圖** | 連續球面的完整世界，具全球自然地理生成與編輯 | 編輯器提供 3D 球體及 20 面體展開；外部以圓柱投影平面檢視 |

- 兩種地圖是不同的建構形式；六角地圖不等同星球地圖的局部詳圖。
- 世界觀保留一個主地表，以及可建立多個的地底、天空附屬空間。
- 國家道路、城鎮、港口、精細海岸等局部設計需求獨立保留，與兩種地圖的關聯方式後續規劃。

## 2. 星球地圖：基礎資料

- 星球為真實連續球面，暫以地球半徑約 **6,371 km** 為參考；距離及面積採球面幾何。
- 生成時建立一套**固定球面 Voronoi Grid**：格子位置、拓樸及 ID 固定；使用者可修改格子的高度。
- 參考 Azgaar 的 **Grid＋Pack**：Pack 是海岸、水文等運算的輔助格網，海陸分布變動時可更新或重建；不以 Pack 格子 ID 當作長期地理物件 ID。
- 陸地與海底共用高度 Grid。低窪地形不會僅因高度低而自動成湖；湖底與湖面水位為不同資料。
- 海岸線依 Grid 的海陸狀態及 Pack 基本邊界生成，再以分形向量細節繪製。**分形擾動只改顯示線條，不修改 Grid 或 Pack**；不另設獨立可編輯的海岸遮罩。
- 面積依球面計算；海岸有效計算邊界及精度須與地圖資料一致。縮放不會重建高解析度 Grid。

## 3. 星球地圖：自然地理生成

1. **海陸配置**：直接隨機選取 Azgaar 風格的「組合／島嶼／群島」素材，隨機決定數量、大小、位置及方向，形成全球海陸分布；**不預設目標陸地比例**。使用者以 3D 球體預覽、接受或重新生成。
2. **板塊**：依確認的海陸與山脈推導地殼類型、板塊、相對運動及邊界；參考 MapRegionizer，適應球面拓樸。單一板塊可同時包含大陸與海洋地殼；保留已確認的地形輪廓。
3. **海底地形**：依板塊形成大陸棚、陸坡、深海平原、洋中脊、海溝及海山，寫入同一 Grid。
4. **表層洋流**：依風帶、科氏效應、海陸阻隔及連通關係推估，影響海表溫度與沿岸氣候；洋流路徑可編輯。
5. **逐月氣候**：以 12 個月的簡化模型計算溫度、降雨等數值，考慮緯度、地形、雨影、風及洋流，衍生氣候類型。
6. **河流與湖泊**：依地形建立初始河湖幾何，另計算河川流量、湖泊水量收支及季節性數值。
7. **生物群系**：由氣候、水分、地形與水域推導；以 Azgaar 主要群系為基礎，適度擴充。

## 4. 地形與水文編輯

### 高度編輯

| 模式 | 行為 |
| --- | --- |
| **保留** | 可選擇只編輯陸地或海洋；限制高度範圍，保持原有海陸分布。 |
| **自由** | 允許陸海互換；海岸顯示及必要 Pack 資料隨編輯更新。 |

- Grid 格網結構固定。Pack 的具體重建時機由實際效能決定，操作時需即時反映結果。
- 使用者可編輯河道、湖泊範圍、湖底、湖面水位與進出水關係；水位與盆地、出水口須維持一致。

### 河湖保護

河流、湖泊各有穩定 ID，保留名稱、詳細資料及相關幾何。

| 設定 | 地形改變時的處理 |
| --- | --- |
| **智慧調整（預設）** | 優先保持原狀；必要時在合理範圍內調整位置、河道、湖岸或水位。 |
| **固定位置** | 維持原有位置及幾何，不由程式自動搬移。 |

- 大幅變動由程式規則處理，不以逐項提醒打斷使用者；不任意遠距搬移或刪除物件資料。
- 超出合理調整範圍時保留物件資料，無效幾何不納入正常水文計算。

### 重新計算自然環境

- 使用者主動執行「**重新計算自然環境**」，更新溫度、降雨、氣候類型、生物群系、河川流量、季節性水量及湖泊水量收支。
- **不改動**河流與湖泊的幾何、水位、板塊、洋流或海陸地形。
- 地形編輯造成的河湖智慧調整，與上述衍生數值重算分開進行。

## 5. 地圖編輯器與外部檢視器

- 星球地圖的 **3D 球體**用於全球觀察、預覽。
- 星球地圖的 **20 面體展開**用於平面地理編輯。使用者可旋轉展開方向；分離但原本相鄰的邊使用**配對顏色與編號**，可手動連接、重排面片。只連接實際相鄰面，避免無效重疊；展開切口不進行跨邊編輯。
- **圓柱投影**是星球地圖外部檢視器的平面顯示方式；其展開經線／左右切口由編輯器設定，與 20 面體排列獨立。
- 六角地圖在編輯器及外部皆使用平面形式。
- 外部地圖沿用世界觀的可重複地圖區塊；各顯示窗可有獨立視角與顯示選項，共用同一地圖及世界觀資料。
- **顯示方式**為主要底圖，例如地形、等高線、溫度、降雨、生態、政治、文化、宗教；**圖層**為可疊加資訊，例如河流、湖泊、邊界、地名、城鎮與路線。
- **編輯器決定外部可用的顯示方式、圖層及觀看範圍**；外部檢視器在允許選項內切換。觀看個別國家或指定範圍，使用既有地理範圍資料，不建立複製地圖。

## 6. 自然地理、人文地理及附屬資料

- **自然地理**保存地形、河湖、板塊、洋流等基礎資料；氣候、流量、生物群系等為可重新計算的衍生資料。
- **人文地理**的國家、行政區、城鎮、文化、宗教、路線及地標，使用獨立正式條目與位置／範圍配置；改變陸海不會自動搬移或刪除人文內容，海底城市可存在。
- 使用者可以建立山脈、森林、沙漠等**附屬地理資料**，記錄名稱、位置／範圍、詳細文字及關聯；不必讓所有自然地形自動產生獨立正式條目。
- 奇幻覆蓋資料獨立於自然模擬，用於呈現與世界觀敘述，不改寫基礎自然計算結果。

## 7. 儲存與同步

- 星球地圖採**完整固定 Grid＋緊湊數值陣列＋獨立地理物件＋差異同步**。
- 優先載入必要的完整世界資料，依視圖繪製所需內容；資料量與效能尚不要求分區載入。
- 地形高度、逐月氣候等採合適的數值陣列；衍生資料依重算成本保存或快取。
- 只同步實際改動的格子／物件，適時整合完整基準，不無限累積編輯差異。
- 沿用 Nexus 現有離線儲存、版本檢查、同步、備份及資料保護機制；地理物件身分不依賴 Pack 暫時索引。

## 8. 待確認事項

- 六角地圖、星球地圖與局部精細設計之間的關聯及資料繼承方式。
- 外部檢視器單獨觀看國家／指定範圍的詳細操作。
- 球面 Grid／Pack、海岸有效面積邊界、20 面體展開與重排的實作精度及效能。
- 高度單位、月別氣候校準、自然地理演算法與生物群系分類門檻。
- 河湖智慧調整的合理變動限制及無效水文資料處理。
- 既有地圖資料的相容方式、實際儲存格式與效能驗證。
