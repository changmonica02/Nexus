# Nexus — 地圖編輯器功能規格

> Nexus 自有世界觀地圖編輯器，提供可持續擴充的自然地理生成、編輯與展示。本文記錄產品需求，包含尚未提供的功能；技術設計及交付狀態另見 [ARCHITECTURE](ARCHITECTURE.md)、[HANDOFF](HANDOFF.md)。

## 1. 世界觀、入口與地圖類型

- **建立入口**：典籍創作頁右上角「建立」提供「世界觀／角色卡」；選擇世界觀後顯示「新建地圖／匯入」，新建地圖再選「新建星球地圖／新建六角地圖」。六角地圖目前為灰色不可選，待後續提供。
- **星球地圖**：連續球面世界，以固定球面 Grid 為基礎；編輯器提供 3D 球體及二十面體展開，平面展示使用等距圓柱投影與水平環繞，編輯器外僅呈現圓柱投影平面圖。
- **六角地圖（後續）**：可持續擴張的六邊形格網，類似《明日方舟》式區域配置，可自由建立區塊及世界觀地理；編輯器內外均為平面。
- **世界空間**：每個世界觀有一個主世界，可擴充地底與天空；附屬空間各有地形與地理配置，透過入口或地標關聯。

## 2. 星球生成與編輯介面

- **生成器**：置中視窗，標題「地圖生成器」及關閉 ×；第一列為地圖名稱（空白提示「輸入地圖名稱」），第二列為星球類型、種子碼、刷新種子碼，第三列為地圖預覽，右下角「生成」。預覽階段僅生成陸地分布；確認生成後才推導地殼、溫度、洋流等自然環境，完成後進入編輯器。
- **生成設定**：地圖名稱、海洋星球（陸地 25%）、類地星球（32%）、陸地星球（45%）及可更改／刷新的 uint32 種子碼。半徑、自轉方向、重力、恆星影響、自轉軸等固定與地球相同，不提供使用者調整。
- **編輯器導航**：頂部從右至左為「⋯（更多操作）」「時間」，左側直排由上至下「工具」「顯示」。顯示面板分為顯示方式、疊加圖層、地圖風格三區，以分隔線區分、內容溢出可捲動。

| 區域 | 選項 |
| --- | --- |
| 顯示方式 | 地形、等高線、溫度、降雨、生態、氣候、政治、文化 |
| 疊加圖層 | 邊界、洋流、河流、湖泊、板塊、省分、地名、城鎮、道路；各自開關 |
| 地圖風格 | 地形、古典、現代、航海、藍圖、夜間 |
| 工具 | 高度、海岸線、河流；湖泊工具後續提供 |

- **縮放與細節**：世界級呈現大陸、海洋、主要山脈及河流；區域級呈現地形細節、湖泊、支流、生物群系、國家及地區；地方級呈現城鎮、道路及較小河湖；細部級呈現小型地形、特殊水文、建築與地標。局部高解析度地形應與全球位置、海陸及高度一致，不以單純放大現有格網代替真實細部；局部資料生成、儲存及編輯方式待確認。

## 3. 地形生成與編輯

- **地形基準**：全球約 3.6 萬格球面 Grid 是陸地與海底共用的正式高度來源；Pack 為沿岸加密、深海稀疏的輔助運算網格，提供岸線、河流及地理物件細節，不是第二套可獨立編輯的高度圖。海平面及與主海洋連通性決定海陸；封閉內陸低地不因低於海平面自動變海或成湖。
- **初始地形**：採有順序的地形操作模板，依種子組合大陸、島嶼、群島候選，選擇尺寸、緯度、經度及旋轉方向，映射至球面、避免不合理重疊並合併為同一全球高度。使用者確認大陸及主要山脈後才推導板塊，後續地質生成不得覆寫已接受的主要地形。
- **高度工具**：保留模式先選「編輯陸地／編輯海洋」，高度限制於對應地形及不跨海平面的合法範圍，岸線不變；自由模式可使陸地沉海或海底升陸，即時更新海陸、岸線及必要地理資料。筆刷提供強制／漸層抬升、強制／漸層降低、平滑、擾動、直線。海岸線及河流提供直接編輯，湖泊編輯工具暫不提供。
- **岸線品質**：保留模板形成的海灣、海峽、島嶼及封閉低地，沿岸使用較密取樣與連續閉合輪廓，呈現平滑轉角及受種子控制的適度粗糙度。陸地填色、海岸描線、近岸帶及河口使用一致輪廓；近岸帶僅覆蓋水域，極區填色補邊不改變岸線，跨經度接縫可連續顯示。保留模式沿用岸線，自由模式改變海陸時重建。

## 4. 自然環境推演

### 4.1 板塊、海底與洋流
- **地質**：依「已確認陸地與山脈 → 合理板塊與地殼 → 海底地形」推導，板塊可同時含大陸及海洋地殼，板塊邊界不等同海岸；區分活動造山帶及歷史造山痕跡，呈現張裂方向及隱沒等特徵。海底包含洋中脊、海溝、海底火山、裂谷、熱點、大陸棚、海底平原及盆地，可合理補充島鏈、火山島，但不改動主要地形。
- **洋流**：依全球風帶、科氏效應、陸地阻隔及海域連通推導簡化表層洋流，路徑可編輯。暖／寒流透過海表溫度（SST）影響沿岸溫度、蒸發及降雨；海溝與洋中脊不作為首版主要表層洋流驅動因素，不模擬三維流體或深層海洋。

### 4.2 氣候、水文與生態
- **逐月氣候**：依緯度與季節日照、高度遞減率、海陸熱差、海表溫度、季節風帶、水氣輸送、迎風坡降雨與背風雨影推導十二個月平均溫度及降雨；水氣沿球面連通與風向傳播，形成沿岸、內陸、地中海型及季風型等差異。降雨須具實際意義的單位及門檻，由月別溫度與降水計算柯本氣候分類；分類不直接改寫基準數值。不提供逐日天氣或多年氣候動力模擬。
- **河流與湖泊**：依坡度、集水路徑、降雨、湖泊及流域形成主河、支流、源頭、匯流與入海口。河湖各自具有穩定身分、名稱、位置／幾何、關聯及詳情，不因輔助網格重建而遺失。河道與湖岸屬基礎地理，月別流量與湖泊水量收支屬衍生結果；乾旱可降低流量或造成季節性斷流，不自動刪除河道。湖底海拔、湖面高度與水域範圍分開，水位依盆地邊緣及出水口限制；湖岸、水位直接編輯屬後續湖泊工具範圍。
- **生態**：以 IUCN 全球生態系統類型第二層下列選定類別為主要分類，依月別氣溫、降雨、水分平衡／簡化蒸散、地形及河湖推導。Azgaar 的 13 類群系僅供生成演算法參考，不合併為平級分類。魔法環境或奇幻生態另作覆蓋，不改寫自然基準。

| ID | 英文名稱 | 繁體中文 | 環境特徵 |
| --- | --- | --- | --- |
| T1 | Tropical-subtropical forests | 熱帶與亞熱帶森林 | 全年溫暖，降水充足或有乾濕季 |
| T2 | Temperate-boreal forests and woodlands | 溫帶與寒帶森林及疏林 | 季節溫差、闊葉林與針葉林 |
| T3 | Shrublands and shrubby woodlands | 灌叢與灌木疏林 | 灌木、低矮木本、季節乾燥或貧瘠土壤 |
| T4 | Savannas and grasslands | 莽原與草原 | 草本為主，樹木稀疏，受降雨、乾旱、火災及草食動物影響 |
| T5 | Deserts and semi-deserts | 沙漠與半沙漠 | 降水少、蒸發需求高、植被稀疏 |
| T6 | Polar-alpine | 極地與高山生態 | 低溫、短生長季、苔原及冰雪 |
| F1 | Rivers and streams | 河流與溪流 | 流動淡水、流域、上下游及季節流量 |
| F2 | Lakes | 湖泊 | 相對靜止內陸水體，深度、鹽度及營養狀態不同 |
| M1 | Marine shelf | 海洋大陸棚 | 較淺沿岸海域，受光照、洋流、潮汐及營養鹽影響 |
| S1 | Subterranean lithic | 地下岩石生態系統 | 洞穴及岩隙，缺乏陽光，受地下水及地質影響 |
| TF1 | Palustrine wetlands | 內陸沼澤濕地 | 長期或季節積水，濕地植被、沼澤及泥炭地 |

- **重新計算自然環境**：使用者完成編輯後手動觸發，更新月別氣溫、降雨、海表溫度衍生值、氣候類型、河川流量、湖泊水量收支及生物群系。河道、岸線等直接編輯與必要地理更新即時反映，耗時的自然環境衍生計算延後至手動重算。不得以重算覆寫已接受的主要地形或刪除既有河道。
- **後續範圍**：淡水湖、鹽湖、冰封湖、石灰華階梯池、IUCN 第三層與局部生態修正不列入目前實作範圍。

## 5. 地形模板與參考範圍

| Azgaar 操作 | 在模板中的作用 |
| --- | --- |
| `Hill` | 抬升局部地形，形成高地、島體、山丘 |
| `Pit` | 降低局部地形，形成低地及破碎缺口 |
| `Range` | 沿路徑抬升，形成山脈／長形高地 |
| `Trough` | 沿路徑降低，形成谷地、裂谷狀地形 |
| `Strait` | 切出狹長水道，分隔陸塊 |
| `Smooth` | 平滑高度分布及邊緣 |
| `Mask` | 依位置施加邊緣遮罩／整形 |
| `Add`、`Multiply` | 加減或縮放指定範圍的高度 |
| `Invert` | 反轉／映射高度配置 |

模板為地形生成配置，不是獨立地理物件。

| 用途 | 主要參考模板 | 核心組成／特徵 |
| --- | --- | --- |
| 大陸群 | **Continents** | 多組 `Hill` 建陸塊、`Range` 建山脈、`Strait` 切水道、`Trough`／`Pit` 分割，配合 `Multiply`／`Smooth`／`Mask` |
| 單一巨型陸塊 | **Pangea** | 周圍與中央的 `Hill`、多條 `Range`、`Trough`、平滑及高度縮放 |
| 複合舊大陸 | **Old World** | `Range` 作主脊，搭配 `Hill`、`Strait`、`Trough`、`Pit`、`Smooth` |
| 破碎群陸 | **Shattered** | 多組 `Hill`、大量 `Trough`、`Range` 及 `Pit` |
| 火山島 | **Volcano** | 高強度 `Hill`、`Range`、`Smooth`、`Mask` |
| 高島 | **High Island** | `Hill`／`Range` 抬升，`Trough`／`Pit` 雕刻，配合 `Multiply`／`Mask` |
| 低島 | **Low Island** | 多組 `Hill`、`Trough`／`Pit`，更強的高度縮放與 `Mask` |
| 半島 | **Peninsula** | `Range`、`Hill`、`Trough`、`Smooth`，搭配高度加值與 `Invert` |
| 群島 | **Archipelago** | `Range`／`Hill` 形成多個島，`Trough`／水平與垂直 `Strait` 分隔 |

## 6. 世界觀地圖區塊與人文地理

- **地圖區塊**：世界觀首頁可透過「新增區塊 → 地圖區塊」加入多個大型顯示窗，各自保存空間、顯示方式、圖層及視角，共用同一份地圖及條目；複製或移除顯示窗不複製或刪除正式地圖。首列為地區單選／顯示方式單選／圖層複選，第二列畫布，第三列預設收合的詳細資料（依選定空間呈現正式條目已儲存正文，不受圖層篩選），第四列右下角保存與同步狀態；空間無條目時提供入口。全螢幕不等於編輯。
- **瀏覽**：首次開啟／切圖等比 fit，最小縮放為 fit，重設回完整視圖；同圖往返及尺寸變動盡量保留中心與縮放，圖層或語言切換不重設視角。一般手機單指捲頁、雙指縮放／平移；全螢幕單指平移、雙指縮放並鎖底頁；雙擊放大、桌面滾輪／拖曳保留。手機不常駐加減按鈕，全螢幕、重設、扳手附著畫布，觸控至少 44px。世界觀管理地圖對話框只提供新建／匯入，既有地圖操作在內容區。
- **人文條目**：初始只生成自然地理，不自動創造國家、文化、宗教、城鎮或歷史。政治體（國家）、行政區、城鎮、宗教、文化只能由地圖編輯器建立／命名，建立即出現在世界觀分類清單，可先不配置。詳細頁可編輯摘要、別名、適用預設及自訂文字／長文／數字／關聯欄位與富文字正文（國家統治者、政體、政黨、歷史；行政制度；城鎮經濟、人物；文化語言風俗；宗教教義、神祇等），不另建平行人文資料或新增／改名入口。地圖改名同步標籤及詳情；正文修改不重建地圖。詳情可前往地圖定位。
- **人文工具**：六類為政治體、行政區、文化、宗教、路線、地標（包含城鎮與地點）；政治體／行政區兩欄，二字類別每列三欄、不足平衡分布。點選類別於側欄原位進入「返回 — 類別名稱」及條目清單、選取／新增／配置、筆刷／擦除／復原重做、移動／路線工具。政治體可自訂王國、帝國等類型，關聯上級、首都、行政中心及文化宗教。手動畫領土、行政區及分布，提供候選預覽、確認／取消；僅繪製模式攔截單指，未確認候選離開須提示。正式國家領土互斥，可表示飛地、無主地及爭議區；行政與正式隸屬不一致提示、不自動改寫。文化與宗教可重疊及跨國，提供個別顯隱、透明度、圖例、高亮，未選取以等權色混合；宗教可分信仰影響、管轄及聖地。
- **尺度與配置**：像素、地理尺寸、座標投影與縮放分離；缺可信尺度顯示相對單位／尺度未設定，不虛構 km²。國家及行政區面積依疆界與實際陸地計算，飛地加總、水域排除，爭議另列且不重複算正式領土。配置狀態未配置／已配置／已鎖定，解除位置或疆界預設保留條目及正文，完整刪除明示關聯後果；刪附屬空間不刪人文條目，轉為未配置。依既有條目產生配置草案屬進階需求，須預覽衝突、保護鎖定及人工確認，不創造新文明或歷史。無獨立區域子地圖；跨空間入口為後續功能。
