# Nexus — 地圖編輯器製作規劃

- **長期定位：Nexus 自有、可持續大幅改良的世界觀地圖編輯器**。以 Azgaar's Fantasy Map Generator 與 https://github.com/yuuranku/planet-simulation 開源程式作為開發起點，優先重用成熟功能、避免首版不必要的重寫
- 權限與授權都已溝通好

## 介面

- 典籍創作頁面的右上角的建立，跳出建立{世界觀} {角色卡}。
- 點擊世界觀後，內容換成{新建地圖}與{匯入}
- 點擊{新增地圖}內容換成{新建星球地圖} {新建六角地圖} (目前六角地圖應該要是灰色的不可點選的部分
- 點擊 新增星球地圖後應該跳到 置中生成器彈窗
標題是 地圖生成器與關閉視窗的差插圖是 
第一行是空格 如果沒有內容會在空格背景顯示淺灰色的( 輸入地圖名稱 )有內容時隱藏
第二行是星球類型 種子碼 種子碼刷新鍵
第三行是整個地圖預覽框 (地圖在初次生成時只生成陸地分布)
第四行是在彈窗右下角的生成
- 用戶點擊生成後 才會開始生成地殻 溫度 洋流...
- 生成完後會跳轉進地圖編輯器頁面

## 地圖類型、空間與世界觀

| 正式名稱 | 地圖基礎 | 用途與顯示 |
| --- | --- | --- |
| **六角地圖** | 可持續擴張的六邊形格網，類似《明日方舟》式區域配置 | 自由建立區塊與世界觀地理；編輯器及外部均為平面地圖 |
| **星球地圖** | 連續的球面世界、固定球面 Grid 與輔助 Pack | 全球自然地理生成；編輯器提供 3D 球體及二十面體展開；外部僅顯示圓柱投影平面圖 |

- 每個世界觀有一個**主世界**，可擴充**地底**與**天空**；附屬空間可擁有各自地形及地理配置，並透過入口或地標關聯。

## 星球資料：球面 Grid、Pack 與海岸線

### 編輯核心與功能

- 進入編輯頁面後，參考 planet-simulation 最上面是從右到左是【...(更多操作)】【時間】最左邊是直排的選單:由上到下是 【工具】【顯示】。
- 【顯示】有三個主題在同一頁以分隔線隔開，捲動方式預覽溢出內容，三個主題有【顯示方式】【疊加圖層】【地圖風格】
- **顯示方式**參考 planet-simulation 與 Azgaar 有{地形}、{等高線}、{溫度}、{降雨}、{生態}、{氣候}、{政治}、{文化}。
- **疊加圖層**參考 planet-simulation 的介面是ON/OFF的開關按鈕有 【邊界】【洋流】【河流】【湖泊】【板塊】【省分】【地名】【城鎮】【道路】。
- **地圖風格**參考 planet-simulation 有 【地形】【古典】【現代】【航海】【藍圖】【夜間】。
- 【工具】參考 Azgaar 有 高度 海岸線 河流 湖泊
- **高度** 點擊高度後有兩種模式{保留}(陸地不會變成海洋){自由}(陸地可以變成海洋)
| 模式 | 規則 |
| --- | --- |
| **保留** | 使用者先選**編輯陸地／編輯海洋**；高度操作限制在對應地形與不跨越海平面的合法範圍，**海岸不變** |
| **自由** | 同一套高度工具可使**陸地沉海／海底升陸**，海陸、必要 Pack 資料及海岸顯示即時更新 |
- **高度**筆刷有 【強制抬升】【漸層抬升】【強制降低】【漸層降低】【平滑筆刷】【擾動筆刷】【直線筆刷】
- 海岸線 河流 直接參考 Azgaar
- 湖泊先不實作


- **陸地與海底共用同一份高度 Grid**；使用同一套地形工具抬升、降低或平滑。海平面作為陸海判定基準；內陸低地不會僅因高度低就自動成湖。湖底海拔、湖面高度及水域範圍是可區分的資料。

### 沿用 Azgaar 的 Grid／Pack 分工
#### 星球視圖

- 底層把整個地球分成約 3.6 萬格球面 Grid 作為全球基礎高度及地理資料來源。
- Pack 作為衍生運算網格，不擁有可獨立修改的正式高度。參考 Azgaar 的第二套 Voronoi 輔助網格：在海岸附近插入額外取樣點、排除部分不需要的深海點，提供海岸、河流及地理物件等運算所需的細節。**不是另一套供使用者直接修改的高度圖**。
- 顯示以等距圓柱投影（Equirectangular Projection）＋水平環繞（Horizontal Wraparound）
- 參考 planet-simulation 的解析度幾何 LOD（Level of Detail，LOD）分塊渲染（Tile-based Rendering）
- 幾何 LOD 與分塊渲染負責不同縮放層級的地形顯示及效能管理；未來局部高解析度地形須維持與全球 Grid 的位置、海陸及高度一致性。
- 局部高解析度資料的具體生成、儲存與編輯方式應在正式實作幾何 LOD 前確定，不以單純放大現有 Grid 代替細部地形。
  
| 層級 | 顯示內容
| --- | --- |
| 世界級 | 全球大陸、海洋、主要山脈、主要河流
| 區域級 | 地形細節、湖泊、支流、生物群系、國家與地區
| 地方級 | 城鎮、道路、較小的河流與湖泊
| 細部級 | 小型地形、特殊水文、建築與地標

## 星球初始生成

- 星球的半徑、自轉方向、重力、恆星影響、自轉軸等等所有都與地球同等，這是系統須知不是用戶可看見或調整之內容
- 用戶操作(重新命名)(星球類型 海洋星球25% 類地星球32% 陸地星球45%) (更改或刷新 uint32 種子碼)
- 生成時參考azg的生成指令
  
Azgaar 的高度模板是由**有順序的地形指令腳本**組成；每行包含操作、次數／強度及作用位置範圍，參數可帶隨機區間。Nexus 要**重用模板思想與各步驟效果**，再將局部結果映射／旋轉至球面，組成多個大陸、島嶼與群島。

| Azgaar 操作 | 在模板中的作用 |
| --- | --- |
| `Hill` | 抬升局部地形，形成高地、島體、山丘 |
| `Pit` | 降低局部地形，形成低地及破碎缺口 |
| `Range` | 沿路徑抬升，形成山脈／長形高地 |
| `Trough` | 沿路徑降低，形成谷地、裂谷狀地形 |
| `Strait` | 切出狹長水道，分隔陸塊 |
| `Smooth` | 平滑高度分布及邊緣 |
| `Mask` | 依位置施加邊緣遮罩／整形 |
| `Add`、`Multiply` | 加減或縮放指定範圍的高度 |
| `Invert` | 反轉／映射高度配置 |

以下名稱來自 Azgaar `heightmap-templates.ts`；**這些是腳本模板，不是 Nexus 要建立的獨立地理物件**。

| 用途 | 主要參考模板 | 核心組成／特徵 |
| --- | --- | --- |
| 大陸群 | **Continents** | 多組 `Hill` 建陸塊、`Range` 建山脈、`Strait` 切水道、`Trough`／`Pit` 分割，配合 `Multiply`／`Smooth`／`Mask` |
| 單一巨型陸塊 | **Pangea** | 周圍與中央的 `Hill`、多條 `Range`、`Trough`、平滑及高度縮放 |
| 複合舊大陸 | **Old World** | `Range` 作主脊，搭配 `Hill`、`Strait`、`Trough`、`Pit`、`Smooth` |
| 破碎群陸 | **Shattered** | 多組 `Hill`、大量 `Trough`、`Range` 及 `Pit` |
| 火山島 | **Volcano** | 高強度 `Hill`、`Range`、`Smooth`、`Mask` |
| 高島 | **High Island** | `Hill`／`Range` 抬升，`Trough`／`Pit` 雕刻，配合 `Multiply`／`Mask` |
| 低島 | **Low Island** | 多組 `Hill`、`Trough`／`Pit`，更強的高度縮放與 `Mask` |
| 半島 | **Peninsula** | `Range`、`Hill`、`Trough`、`Smooth`，搭配高度加值與 `Invert` |
| 群島 | **Archipelago** | `Range`／`Hill` 形成多個島，`Trough`／水平與垂直 `Strait` 分隔 |

- **Nexus 的組合方式**：隨機抽取多份大陸／島嶼／群島候選模板 → 對每份選擇尺寸、緯度、經度與旋轉方向 → 轉為球面局部地形 → 安排整體大陸配置，避免不合理重疊 → 合併到同一固定 Grid 的高度資料。
- 大陸 (**Continents**、**Pangea**、**Old World**、**Shattered**)島嶼 ( **Volcano** 、**High Island**、**Low Island**、**Peninsula**) 群島 (**Archipelago**)
- 使用者**確認大陸／山脈之後**才推導板塊；後續地質生成不得擅自改動已接受的陸地輪廓或陸上主要地形。

## 推演世界

### 板塊與海底地形：參考 MapRegionizer 與 planet-simulation 的生成

- **採用「已確認陸地與山脈 → 合理板塊與地殼 → 海底地形」**，不先用板塊生成覆蓋掉使用者接受的大陸。
- **一塊板塊可以同時有大陸地殼與海洋地殼**；板塊邊界不等於海岸。現有山脈有些可成為活動造山帶，有些是歷史造山痕跡，不能全部強制視為活動碰撞邊界。
- 板塊要有張裂的朝向與海洋與陸地板塊隱沒等特徵
- 海洋地形要有 : 洋中脊、海溝、海底火山、裂谷、熱點、大陸棚、海底平原、海底盆地等 並在合理範圍補充島鏈 火山島等陸地特徵 但不動到主地形

### 全球表層洋流

- 採**簡化表層洋流**，使用全球風帶、科氏效應、陸地阻隔及海域連通推導大尺度流向，不做三維流體或深層海洋模擬。
- 洋流路徑屬基礎自然地理，使用者可修改；其暖／寒流效果先影響**海表溫度（SST）**，再影響沿岸溫度、蒸發與降雨。
- 海底海溝與洋中脊**不直接作為第一版表層洋流主要驅動因素**。

### 十二個月的簡化氣候

- 依緯度／季節日照、高度遞減率、海陸熱差、洋流海表溫度、季節移動風帶、水氣輸送、迎風坡抬升降雨、背風雨影等計算**12 個月的溫度及降雨**。
- 全球水氣傳播採球面連通與風向，不照搬 Azgaar 從平面地圖邊界逐列輸入的處理；沿岸與內陸氣候需能產生地中海型、季風型等季節差異。
- 由月別溫度與降水歸納**柯本氣候類型**等計算分類；類型不是使用者直接改寫的基準數值。
- 原 Azgaar 的降雨強度不是 mm／月；**須校準至有實際意義的單位與門檻**，避免以錯誤數值套用氣候分類。
- 只做逐月氣候平均，不建立逐日天氣或多年氣候動力模擬。
- 參考 Azgaar：[溫度生成器](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/src/model/physical/temperature-generator.ts)
- 參考 Azgaar：[降雨生成器](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/src/model/physical/precipitation-generator.ts)

### 河流與湖泊

- 初始參考 Azgaar 河流生成邏輯，依坡度、集水路徑、降雨、湖泊及流域形成主河、支流、源頭、匯流與入海口。
- **河流及湖泊有獨立穩定 ID**，保存名稱、位置／幾何、關聯與詳細資料。不能因 Pack 重建而遺失身分。
- **河道／湖岸／是可編輯基礎自然地理**；月別流量、湖泊水量收支等為衍生結果。氣候變乾可以讓河流流量降低或出現季節性斷流，但**不因此刪除河道**。
- 湖底地形、湖水表面與範圍分開；設定水位時依盆地邊緣與出水口檢查合理性，不讓水位無條件高於封閉盆地邊界。

###  「重新計算自然環境」

- 使用者編輯完成後**手動觸發**；更新**月別氣溫、降雨、海表溫度衍生值、氣候類型、河川流量、湖泊水量收支、生物群系**等計算結果。。
- 河流／湖泊的直接編輯與必要資料索引**即時更新**；昂貴的自然環境衍生計算才延後。

## 六角視圖

- 六角地圖外部亦為平面。
