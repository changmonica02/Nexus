# Nexus — 字典功能規格

> 字典為集中管理的公開詞條資料庫，供一般閱讀及私人字卡查閱。本文描述產品功能與操作契約；技術架構及交付狀態另見 [ARCHITECTURE](ARCHITECTURE.md)、[HANDOFF](HANDOFF.md)。規格包含既有及規劃功能，不代表全部已交付。

## 1. 詞條與搜尋

- **詞條類型**：單字（Word）、構詞（Prefix／Root／Suffix）。詞條與義項有獨立正式識別，字形、相似拼寫及中文提示不能代替正式關聯；不自動推測詞源、建立或發布詞條。單字忽略大小寫及首尾空白後維持拼寫唯一；合法同形構詞可有不同識別。
- **搜尋介面**：依序為「全部／單字／構詞」單選分頁、搜尋框與放大鏡、大分類列、小分類列及上方分頁。僅構詞分頁顯示字首／字根／字尾複選篩選（預設全選）；大分類含總覽及十大語意分類，窄畫面可水平捲動但不造成整頁溢出。選擇有小分類的大分類才顯示小分類列；總覽不額外限制，派生構詞無小分類。
- **搜尋與排序**：搜尋名稱、構詞變體、中文義、概述、詞源及相關內文；依正規化名稱完全相符、名稱前綴、變體完全或前綴、名稱中段、中文義／詞源／其他內文的順序排列，同層以較短名稱及穩定順序處理。完整候選排序後才分頁；構詞摘要呈現「構詞／變體 — 義項；義項」，不因多義項或變體重複列出。
- **瀏覽狀態**：列表上、下方同步提供「上一頁／第 X 頁・共 Y 頁／下一頁」；搜尋、類型、分類、頁碼、返回與前後筆導覽共享狀態，一般與管理字典採相同核心搜尋配置。

## 2. 詞條內容與正式關聯

### 2.1 單字
- **編輯順序**：構詞分段與連結、IPA 讀音、記憶法、義項及衍生義、詞源、筆記。構詞至少一段，每列為「英文字形｜中文提示｜刪除」，尾端可新增；各段可選取、更換或解除正式詞條／義項連結。IPA、記憶法、詞源及筆記各維持一個固定欄位。
- **義項**：至少一個，可增減；詞性與中文短義並列，每個義項可有零至多個衍生義，每個衍生義可附零至一組英文例句及中文翻譯。

### 2.2 構詞
- **編輯順序**：構詞名稱、類型（字首／字根／字尾）、各義項的大分類、小分類、變體、變體出現條件、概述、詞源、連接單字。單字關聯可雙向建立與解除；已發布義項的概述供單字構詞連結預覽，無概述則不顯示，不以詞源或推測補足。
- **語意分類**：支援未分類及下列參考 SIL Semantic Domains 的分類。

| 大分類 | 小分類 |
| --- | --- |
| 物理動作 | 姿態、移動、作用、分離、結合、持有、操作 |
| 空間與時間 | 方位、距離、位置、時間、順序、範圍 |
| 宇宙與自然 | 天體、地理、物質、植物、動物、自然現象 |
| 生命與人體 | 身體、生理、感官、生命活動、健康與疾病 |
| 語言與心智 | 語言、認知、思維、學習、記憶、情緒、意志 |
| 社會與人文 | 人際、法律、政治、權力、文化、宗教、對抗 |
| 生活與工作 | 居住、飲食、衣著、製造、農業、工具、交易 |
| 狀態與性質 | 大小、形狀、數量、程度、優劣、特性、存在、變化、部分與整體 |
| 文法與詞綴 | 否定、反向、重複、語法關係 |
| 派生構詞 | 無小分類 |

### 2.3 關聯操作
- **正式關聯**：候選顯示名稱、類型及必要義項，支援選取、更換、解除、反向查詢及排序。預設適用整個詞條，勾選「僅適用特定義項」才顯示義項選擇器；取消勾選才解除義項限制。既有關聯不因初始化、收合、資料暫缺、義項數量或分段順序改變而靜默失效。重複、查無候選、非法關聯或衝突須明確提示；不顯示逐筆舊查證狀態、查證說明或關聯種類欄位。
- **快速建立構詞**：管理員搜尋不到適合構詞時，可經確認選擇字首／字根／字尾，建立僅有合法名稱的最小詞條並返回原編輯器供選取。不得自動填入中文義、分類、詞源或依搜尋字串自行建立／發布；多個同形候選須人工選擇，建立及關聯須保持完整一致。此例外不適用單字。

## 3. 閱讀與學習

- **一般字典詳情**：連續閱讀、預設全部展開，以標題、段落與留白區分構詞、讀音、記憶法、義項／衍生義、例句、詞源及筆記，不為每段加框或摺疊。單義項不編號，多義項採精簡序號；單字詞性與中文短義並排，構詞依字形順序呈現中文提示與有效連結，未連結不提供跳轉。不顯示技術用語或私人字卡數量、建立及連結資訊。
- **詳情操作**：頂端提供返回、關閉，僅管理員可見位置固定且與關閉區別的「編輯詞條」；發布後重新讀取已發布內容。返回真實來源並保留搜尋、篩選與頁碼；有瀏覽脈絡時提供上一筆／下一筆，手機與平板可左右滑動但不干擾內文捲動。
- **學習內字典面板**：字卡翻面後由底部「查看字典」開啟；有正式連結直接顯示已發布詳情，無連結則進入搜尋。第一列「返回｜拖曳把手｜關閉 ×」，第二列「搜尋框｜放大鏡」，下方為完整閱讀內容，詳情右上角僅管理員可見鉛筆編輯入口。返回處理面板內歷程，關閉或下拉回到原卡並保留 Session、翻面及評分狀態；面板開啟時防止誤觸評分，保留鍵盤、焦點、觸控、捲動及未儲存編輯保護。

## 4. 管理、草稿與發布

- **管理清單**：頁首左側依序「新增／匯入資料／匯出資料」，窄畫面縮放而不換行。工作狀態可複選「待審核」（紅）、「有草稿」（黃）、「新發布」（綠），全未勾選表示不過濾，複選取聯集。紅為未解決匯入疑義或阻擋，黃為未發布草稿／審核草稿，綠為已發布且無待決差異及草稿，優先紅＞黃＞綠；新發布無時間限制，紅不表示公開內容失效，綠不表示語意已自動查證。寬／中／窄畫面分別三／二／一欄，顯示名稱、形式、狀態及一致瀏覽順序。
- **編輯與儲存**：由管理清單直接進入可修改表單，優先載入有效草稿，否則載入已發布版本；僅開啟不建立草稿。兩種版本皆存在才顯示「最新版本／草稿」切換。緊湊分區，清楚顯示未儲存、儲存中、已儲存草稿、失敗及儲存／發布操作，不遮蔽輸入或顯示不必要技術版號。
- **自動儲存**：單行 Enter／失焦、行動裝置完成／失焦、選單及結構增刪後儲存有效且已變更的整份草稿；長文字 Enter 換行，中文組字中不提交。必要欄位暫缺時保留輸入並提示待完成；失敗、中斷、版本衝突保留輸入，不讓舊回應覆寫新修改。手動儲存可立即保存或重試，成功留在編輯頁；離開未儲存內容提供儲存／放棄／繼續編輯。
- **前後筆與發布**：編輯頁依來源清單跨頁順序提供上一筆／下一筆，首尾停用，切換前確認儲存，失敗或衝突留在原詞條。管理員查證後可單筆發布有效已儲存草稿；特殊審核草稿須先核准。「發布全部草稿」涵蓋全字典符合條件者，不受當前篩選限制，提供預覽、確認、進度、恢復及阻擋原因，不繞過個別審核。
- **刪除與審核入口**：既存詞條可由管理員確認刪除；其他正式詞條或官方集引用時阻擋，不連帶刪除私人字卡或學習歷史。未儲存的新詞條不顯示刪除。一般編輯器不常駐大型審核面板，無待審核則隱藏，有待決差異才顯示精簡提示及入口；移除右側固定「開啟未審核詞條／發布全部草稿」操作，保留上述功能，其他入口位置待確認。

## 5. 匯出、匯入與審核

- **交換範圍**：正式字典為唯一權威資料，日常修改在 Nexus 管理介面完成，批次增修使用完整交換檔。接受並忽略已退役的讀音 locale、note；淘汰的原始字形註釋及未知欄位不接受。匯入檔未列出的詞條或子項不視為刪除，取代既有資料須有明確差異與確認。
- **匯出**：視窗依序為標題／關閉、範圍、開始完整匯出。類型可選全部、單字、構詞及字首／字根／字尾，狀態可選全部或真正待審核；組合篩選涵蓋全部符合詞條而非目前頁，空選不視為不限。顯示範圍、筆數及進度，結果提供完整 JSON 下載及相同內容重新下載；中斷可重試／恢復，期間資料有影響輸出的變動則要求重匯出。
- **匯入視窗**：第一層含標題／關閉、預設收合格式說明、選擇檔案、貼上／檢視內容框、右下角「分析」；分析不寫入。第二層含標題／說明／關閉、總筆數、安全／待審核／不通過筆數與預設收合的三組清單，展開才分頁或讀取差異。各筆依狀態提供匯入、保留現有、排除或重新檢查；排除僅略過本次，不刪正式詞條。
- **安全分類與套用**：安全為可明確辨識的合法新詞條、無衝突新增義項／附屬資料或空白補值，只寫草稿；未變更略過；待審核為修改、覆寫、刪除有效內容或身分、義項、關聯疑義，混合安全與爭議時整筆列待審核並標示可安全部分；不通過為格式、身分、版本、權限或關聯等阻擋。「匯入安全詞條」僅處理整筆安全內容；「匯入全部」另將待決差異送入常駐審核，不自動核准或公開，不通過不寫入。
- **作業與資料保護**：一次啟動、分批處理、顯示總進度及結果，可恢復與安全重試，不重複建立或以舊結果覆寫新內容。匯入前後確認識別、類型、歸屬、版本、相依關聯及管理權限；不以 JSON 合法、AI 說明或字形相同當作語義查證。一般讀者僅讀取已發布內容，管理及草稿操作限授權管理員。
