## 2026-11-04

- **生活自訂清單與離線同步（PR #142）**：完成多份清單、多層分類、自訂欄位、附件及既有同步與備份整合。已由使用者在正式 Supabase SQL Editor 套用相關 Migration，驗證資料表、權限與同步設定後合併；該操作未登錄在 Migration ledger，日後自動套用須避免重複執行。
- **生活清單多種檢視（PR #144）**：整合 TanStack Table 表格、欄位顯隱與順序、排序、篩選、分組及多層分類樹；清單、卡片、表格與分類樹共用資料與編輯流程，檢視偏好依帳號及清單保存在裝置端，不跨裝置同步。本階段完成後暫緩生活功能後續擴充。
- **字卡學習頁改版（PR #145）**：集中頂部組名與本批完成進度，放大卡面，支援點擊正反翻轉、英文旁發音圖示及答案優先呈現；改善語音播放生命週期與手動重播。學習首頁日曆與學習組面板可點擊遮罩關閉，關閉鍵改為叉叉圖示，日曆快捷入口改為「生活」。
- **唯一三按鈕排程（PR #146）**：以「忘記／模糊／記得」取代 FSRS 與舊固定排程切換。新卡與複習卡共用預設 1 分鐘／10 分鐘／7 天，忘記卡為 1 分鐘／10 分鐘／1 天，各組可自訂六個間隔；忘記留本批待到期，模糊及記得退出本批。保留舊 due、FSRS 記憶、學習歷史與未完成 Session 的相容處理，修正新卡門檻與斷網續作。
- **世界觀首頁與地圖整合（PR #147）**：確立首頁上方為適中高度的地圖卡片、下方為世界觀條目與詳細資料撰寫區；只有完整編輯器以地圖為主。整合國家、行政區、城鎮、文化、宗教等正式人文條目，支援自訂欄位、地理配置與解除配置；地圖工具整理為自然地理、人文地理、顯示與樣式，保留原生地圖儲存、匯出及舊資料相容。
- **全站介面一致性（PR #148）**：側邊欄項目補齊更多操作，與首頁共用排序、分類與偏好；一般次級頁面統一頂部側欄、返回及標題，管理學習組三個主要動作集中同列。帳號選單於備份下方新增紅色登出；字卡三個回答在手機、平板及桌面均為等寬三欄，發音失敗提示移到英文上方，避免遮住答案。
- **字典與側欄簡化決策**：確認字典詳情不再顯示私人字卡加入、數量及開啟入口，既有私人卡片、詞條連結與學習資料仍保留；側邊欄分類集中於原有排序選單，不另佔一列。相關 SPEC 於當日更新，程式整合於翌日合併的 PR #149，不列為本日已合併成果。
- **驗證與待辦**：上述合併工作完成相關型別、建置、資料、瀏覽器與 PWA 離線回歸；PR #148 曾因獨立測試環境缺少 Next.js 編譯期設定而失敗，修正後 GitHub Actions 通過。Safari／iPadOS 實際發音、觸控、地圖工具及安裝 PWA 的實機操作仍待驗收；#145–#148 未新增 Migration，不代表所有實機情境已確認。

## 2026-10-20

- **世界觀地圖資料及引用模型（PR #99 當時待審）**：以既有 Page JSON 的可選 world_entities 與地圖 metadata 的 placements 表達正式人文條目及地理配置；識別碼與名稱、正文與位置分離，沿用 CAS、outbox 與備份，不另建平行資料庫。原生 `.map` 保留引擎內容，Nexus 完整備份另含條目與引用。
- **自主地圖核心與離線儲存**：將固定版本 Azgaar 原始碼納入 Nexus 管理的 fork，分離核心、嵌入橋接與介面；公開核心資產經隔離快取支援離線，核心不得取得帳號憑證或私人 API。地圖附件、修訂及復原狀態沿用既有原子同步與備份機制。
- **地圖瀏覽及編輯操作**：採行動裝置優先的嵌入式地圖、contain 顯示與手勢控制，分離瀏覽鏡頭、編輯狀態與圖層；切換地圖以文件身分防止誤存，不將顯示適配寫回原生資料。世界觀首頁取消角色資料編輯介面，但保留原始欄位。
- **自然生成與文明配置分離**：自然地理使用原生演算法與明確步驟，人工文明／地標配置只透過衍生標記呈現；涉及海陸拓撲或水文、生態重算的高風險操作暫不承諾安全保留人工資料，完整重生須另有確認、快照與回復流程。
- **驗證與限制**：當時完成分層契約、TypeScript／建置及隔離瀏覽器驗證；各工作分支及 PR 的合併狀態不能由單項測試結果推定。未經正式帳號、跨裝置或 Safari／iPad 實機完整驗收，亦未操作正式資料庫。

- **簡化字典介面**：全面移除逐筆內容的審核與查證狀態欄位，不再顯示「待審核」等資訊。

- **修復發布按鈕**：解決部分字典草稿只能儲存、無法發布的問題，適用於單字、字首及字根。
- **字典詳情顯示調整**：學習過程中查看字典詳情時，改為直接在目前畫面開啟浮動視窗，不必離開原本的學習頁面。
- **修復內容發布問題**：修正部分字典內容在儲存、捨棄修改或發布時可能發生的錯誤。
- **移除舊字形註釋**：移除不再需要的自由文字字形註釋欄位，同時保留有效的構詞提示及其他必要資訊。
- **學習中直接編輯公開字典**：管理員在正式學習模式翻開字卡並展開字典詳情後，可以直接開啟完整的詞條編輯器，修改公開字典內容，而不影響私人字卡或測驗評分。
- **私人字卡連結改善**：將私人字卡的來源紀錄與目前連結的公開字典詞條分開處理，使使用者即使解除字典連結，也不影響既有下載與更新紀錄。
- **詞性與中文意思並排**：調整單字編輯介面，讓每個詞性的中文意思顯示在同一列，方便新增、修改與管理不同義項。

- **建立獨立創作資源庫**：與原本的學習資源庫分開管理，讓創作內容有獨立的投稿、下載及管理流程。
- **公開與私人版本分離**：首次確認投稿後即可公開；日後修改私人版本時，不會直接影響公開內容，必須再次確認發布才會更新。
- **下載與內容管理優化**：改善資源下載、來源紀錄及跨裝置同步方式，避免重複建立資料。
- **模板改為純結構設計**：模板只保留欄位、區塊與排列方式，不再自動帶入範例文字、角色內容、數值或附件。
- **模板管理獨立化**：可在專屬管理頁面直接調整模板結構，並自動儲存變更。
- **改善模板更新機制**：強化角色與模板之間的結構對應，為後續更新與維護提供更穩定的基礎。
- **保留既有資料**：不會因新模板規則而直接清除過去已建立的角色內容。
- **區塊式角色卡**：將角色卡改為更靈活的區塊預覽形式，方便調整內容位置與版面配置。
- **浮動視窗編輯**：透過浮動視窗修改區塊內容，關閉前會先確認儲存，避免變更遺失。
- **操作體驗改善**：支援長按及鍵盤操作來調整區塊，並保留空白區塊與完整文字顯示。
- **舊資料相容**：延續原本的角色資料格式，保留既有欄位、附件與相關內容，不強制重新建立角色卡。
