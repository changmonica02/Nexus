# 我的清單重構

基準提交 `c9347a4c3eb6b5926f067d31aa08122953868763`。由 `feature/life-calendar-refinement` 的草稿 PR #234 交付。

## 既有架構

`life_lists`、`life_categories`、`life_items` 已具備穩定 ID、型別驗證、欄位封存、資料轉換預覽、私人附件、同步與帳號隔離。本次延用清單編輯、共用表格、統計及離線同步。原有分類樹與檢視偏好相容。本階段新增的庫存資料只屬於我的清單。

## 已實作

- 首頁搜尋清單、項目文字與庫存位置，提供置頂、資料夾名稱分組、清單或卡片排列、架構複製、封存、恢復與庫存提醒。
- 快速清單預填完成及備註欄，內建範本依用途配置欄位，也可另存清單架構為自訂範本。庫存類範本會啟用庫存操作。
- 清單、表格、圖庫、看板及原有分類樹共用項目。看板支援分類或單選欄，提供拖曳和選單移動。具名檢視儲存篩選、排序、欄位配置與分組。
- 以容器為單位追加正式庫存紀錄。同批容器各自追蹤開封、移動、使用、盤點、估算、丟棄與末筆復原。
- 位置可跨清單共用。移動後保留歷史。刪除有現存容器或子位置的位置前，需先移走內容。
- 提醒支援保存期限及剩餘容器門檻。庫存容量依相容單位彙總。消耗統計只計算實際使用並排除已復原項目。
- CSV 依欄名匯入，預先驗證型別並略過同名項目。CSV 匯出處理試算表公式注入。JSON 匯出包含設定、分類、項目、庫存異動與相關位置，省略私人附件內容、參照及跨模組連結。

## 遷移與復原

1. 測試環境先執行既有 Life migration 至 `20261128040000_life_task_action_slots.sql`。
2. 再執行 `20261128050000_life_list_inventory.sql`。此 migration 建立兩個庫存資料表、索引、RLS 與完整性檢查，並擴充現有同步 RPC。
3. 以兩個測試帳號檢查庫存資料隔離，驗證重送、舊版本更新、負庫存及容器復原，再檢查既有清單能讀取及編輯。

既有清單及項目不需資料回填。不需移除任何既有欄位。若需回退前端，保留新增資料表及異動歷史，讓舊版繼續讀取既有清單。加入庫存的清單可停用庫存操作，既有紀錄仍保留。整體工作區備份尚未納入庫存匯入復原，庫存可用單清單 JSON 匯出保留。
