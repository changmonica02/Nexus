# Nexus — 產品規格（使用者畫面與操作契約）

> 以功能模組為單位，描述使用者從何處進入、看見哪些 UI、如何操作、可以修改哪些設定，以及操作後的結果。未確認的尺寸、手勢、預設值與流程標示「待核准」。產品歷史記於 [HISTORY](HISTORY.md)，程式修改與驗收狀態記於 [HANDOFF](HANDOFF.md)，技術及資料庫設計記於 [ARCHITECTURE](ARCHITECTURE.md)。

## 文件閱讀方式
- 各 `F-*` 章節是產品需求主要來源；同一功能的入口、畫面、操作、設定與資料集中紀錄。
- 精確 UI 位置、順序、大小、間距、導覽、狀態和跨裝置差異，一旦確認即寫入所屬模組，不另建立重複總表。
- 使用者未設定而ai自行設定的規格也要紀錄於此，方便後續的調整

## 功能規格

### F-HOME — 首頁
- 側邊欄「新增+」按鈕，應對應新建功能跳出相應的格式選擇，例如:筆記-分頁、流動，創作-世界觀、角色
- 排序下拉新增「依照項目類型」勾選框

### F-NOTE — 筆記

#### 功能定位與入口
- Nexus 筆記是一種可自由編輯的富文字內容，使用者可以透過同一套編輯工具製作一般筆記、整理資料、題庫、測驗題、考卷或類似講義的內容。
- 使用者從首頁、筆記清單或新增功能進入筆記；開啟筆記後直接進入同一筆記編輯器，並可使用側欄、搜尋及既有工作區導覽返回。
- 筆記的內容及排版會持續儲存；重新開啟、重新整理、備份與同步後仍保留。
- 側邊欄項目隨時可拖拽（拉出/拉入子頁）

#### 筆記畫面與編輯工具
- 筆記編輯區提供標題、正文、富文字工具列與「插入內容／格式」等工具入口；既有工具以相同互動方式供所有筆記使用。
- 可使用段落、標題層級、粗體／斜體等文字樣式、項目符號、編號清單、引用、連結、待辦清單、表格、提示框、程式碼、行內與區塊數學式。
- 可使用二欄／三欄、多種文字方向、圖片與圖說、手動分頁，以及拖曳把手調整區塊次序。不同工具在其適用的內容位置提供插入、編輯、移動和移除操作。
- 插入工具及格式設定在桌面／平板／手機保留可觸達入口；窄螢幕可透過「更多」選單提供完整工具清單，浮動選單維持在可視範圍內。
- 右鍵或相應的觸控選單可對文字、區塊與表格執行適用操作；文字選取和系統鍵盤不應遮擋主要編輯目標。

#### 題目、題號與選項（通用筆記編輯能力）
- 使用者可以在筆記的任意位置插入題目內容，不限於特定筆記類型或版面。題目可搭配文字、數學式、圖片、表格及其他筆記區塊。
- **題號**：可插入自動編號題目，按內容順序編號；新增、刪除、拖曳或調整題目順序後，題號隨之更新。題號起始值、編號樣式、分段重新編號與巢狀規則待確認。
- **選項**：可在題目內插入多個選項，包含選項標籤與可編輯內容；支援常見單選題 A／B／C／D 類排列，也可按需求增減選項。選項標號樣式、橫向／縱向／多欄排列、長內容換行與編輯方式待確認。
- **答案與解析**：可在題目後插入答案或解析區塊，內容可編輯；提供展開／收合能力，方便在編輯或檢視時按需要顯示。
- **作答空間**：可在任意段落或題目後插入留白區域，供閱讀、列印或手寫作答使用；留白高度／行數可調，預設值待確認。
- 定義、例題、練習、解答及重點等語意區塊可作為一般筆記的插入內容；可設定區塊標題、內容及可用的展示方式。
- 題目、選項、答案和其他編輯區塊能與普通段落交錯排列，並保有完整的剪下、複製、移動、儲存、匯出及復原能力。

#### 內容組織與導覽
- 使用者可依標題層級產生自動目錄，點擊目錄項目跳轉到所屬標題；增刪或修改標題後更新目錄文字與定位。
- 支援標籤、資料夾、頁面連結、反向連結、附件及內容區塊編排；筆記可與工作區其他資料建立關聯。
- 圖片可設定圖說，題目及圖表可具有可辨識的編號或參照資訊；跨區塊引用的操作與自動更新細則待確認。

#### 版面、列印與匯出
- 筆記支援流動（Flow）、A4 分頁等版面設定，並可調整正文字級、行距、標題樣式、內距、頁首頁尾及頁碼等適用選項。
- 分頁筆記可使用手動分頁；使用者可主動執行「依 A4 整理分頁」，檢查區塊高度與排版，在合理範圍內維持標題與內容、圖片與圖說及題目與選項的相鄰關係。整理後可復原。
- 列印及 PDF 匯出呈現筆記內文、題號、選項、答案、圖說、頁碼與頁首頁尾；收合內容在列印時仍應完整輸出。
- 筆記可列印、匯出 PDF，以及透過 Nexus JSON 或工作區備份保留完整可編輯內容與格式。Markdown 可作內容交換用途，其支援格式依筆記與 Document 各自的匯出契約處理。

#### 設定與待確認事項
- 筆記相關設定依適用範圍保存：全站偏好、單篇筆記版面設定，以及個別題目／區塊屬性分開處理。
- 題號樣式、選項預設數量與排列、答案顯示狀態、作答空間預設高度、工具列位置及尺寸、手機觸控插入流程均待使用者確認；在定案前保留現有一般筆記的操作方式。

### F-DOCUMENT — Plain Document

- **文檔（F-DOCUMENT）**：純文字與 Markdown 導向的文件編修和匯入匯出。

- **目的**：適合文章、報告、正式文字與 Markdown 工作流。
- **編輯模式**：`plain` editor variant；不承擔 Note 的 rich typography 工具列。
- **格式**：以 flow／A4／custom 為主；Document 預設 A4 的目前規則見 F-PAGEFORMAT。
- **匯出**：Markdown；需在 export 前 flush save。
- **定位**：Document 為純文字／Markdown 導向的獨立編輯流程，Note 為富文字筆記編輯流程。

#### 文件匯入與匯出

- 使用者可將 `.md`、`.markdown`、`.txt` 匯入為 Document；匯出 Markdown 前保存當前編輯內容。

### F-PDF — PDF 文件與研究筆記

- **PDF 研究（F-PDF）**：PDF 匯入、檢視、附檔及關聯研究筆記；進階 PDF 工作空間待細化。

#### PDF 匯入與 Research Note

```
選擇本地 PDF
→ 建立 Attachment metadata
→ 寫入 binary
→ 自動建立 Research Note Page
→ attachment_ids / primary_attachment_id 關聯
→ 顯示 PDF viewer 與研究筆記
```

- PDF binary 不放入 `content_json`；以 attachment／asset 管理。
- 一篇 PDF 對一篇主 research note 是起步 UX，不是資料模型硬限制。
- Viewer 現有 Open、Small/Medium/Large、Hide/Show、loading/unavailable/normal 三態。

#### PDF 文件工作空間（待定案）

- **使用者要求**：PDF 應以「匯入」形式進入 Nexus，形成類似 GoodNotes 的 PDF 文件工作空間，而不是把 PDF 視為一般 rich-text insert。

- **相容性**：PDF 文件工作空間與 Attachment／Research Note 的既有資料及操作流程相容。

#### PDF 匯入與文件整理

- 使用者選取 PDF，系統建立附件並開啟關聯的 Research Note 與 PDF viewer；進階 PDF 文件工作空間的手寫、註解及頁面操作待核准。

### F-STUDY — 學習集與字卡

- **學習集（F-STUDY）**：私人字卡、FSRS-6 每日學習／複習、字典資訊展開。

- **資料方向**：Deck = Page（設定另存）；Card = 使用者擁有的獨立 `study_cards` 記錄＋`study_states`（個人排程狀態）＋`study_events`（個人 append-only 事件）＋`study_settings`（每學習集設定）。字卡的英文／中文及個人編輯內容與公共百科相互獨立；未來可選擇連結公共字典的穩定詞條 ID 取得補充資訊，**公共字典不能覆寫個人字卡，也不持有個人 FSRS 排程**。
- **演算法**：固定 `ts-fsrs 5.4.2`（FSRS-6）；`request_retention = 0.90`；`learning_steps = ['10m']`；`relearning_steps = ['10m']`；`enable_fuzz = false`；`maximum_interval = 36500`；完整參數存入每筆事件。按鈕間隔取 `scheduler.repeat`，提交用 `scheduler.next`，不覆寫 `due`。
- **每日練習**：僅英→中主動回想；先只顯示英文，「顯示答案」後才顯示中文與 Again／Hard／Good／Easy。每個學習集預設每天 20 張新字（可設 0–10000），裝置當地 00:00 換日。題面掛載後以交易確認首次顯示才扣額度，交易完成前不能揭露答案或評分。**當日新字批次首次實際學習才建立，固定且跨重新整理持久化；每張新字必須 Easy 才完成，僅建立 `kind: introduce, source: daily_learning` 管理事件及 `learned_at`，不可捏造 Again review event 或正式 due。** 
- **正式單字複習**：固定持久化 session，預設目標 20 張；New 優先（隨機）→ Due 隨機 → Not-due 按最近到期補位。每張卡**本輪首次評分**才寫正式 FSRS review event／due，後續重練只更新 session mastery。Again／Hard 重排；Good／Easy 均完成出箱。`easy_at` 暫保留作相容性完成標記。

- **既有卡片資料相容**：使用者可預覽、確認字卡英文與中文內容，再啟用每日練習；欄位不完整的字卡仍可保存，且僅內容完整的卡片進入出題。
- **編輯與複製**：中文修改保留排程；英文修改提供保留／重設／取消（重設以新 generation＋`reset` 事件，歷史仍保留）；單卡與整個學習集複製只複製內容並建立 New 卡；刪除為 soft delete。
- **雙裝置衝突**：兩台裝置離線回答同一張卡時，保留所有事件，標記 `conflict` 並停止該卡正式排程；使用者須明確選擇「保留歷史並重新學習」。不自動推測語義合併。
- **匯入**：支援 CSV／TSV 格式的學習集資料匯入。
- **字卡編輯列表**：以英文 A–Z 呈現兩欄 English／Chinese；長文字單行省略，點選整列開編輯，顯示完整內容；列表依英文排序展示，使用者儲存的自訂順序獨立保留。
- **翻面後資訊及儲存提示**：僅每日學習／正式複習背面顯示展開字典詳情；順序為四個評分按鈕 → 詳情面板 → **詳情內容末端隨捲動顯示**的儲存狀態提示（B2）。儲存進行中顯示；成功消失，失敗同位置提示／重試；展開詳情維持 FSRS 評分與排程狀態。
- **離線資料邊界**：系統在一般重新整理與離線期間持續保留已寫入的本地學習資料；備份和跨裝置同步依帳號設定與備份流程執行。

#### 學習集與練習入口

- 從 CSV／TSV 匯入個人字卡內容，提供欄位對應及資料錯誤提示。
- 每日學習與正式複習使用各自的操作流程及進度紀錄。
- 近義詞群組、雙向拼寫及容錯練習的題型與設定待核准。


### F-DICTIONARY — 字典

#### 公共字典與入口
- Nexus 提供一套公共字典，所有有字典閱讀權限的使用者均可查看**已發布內容**；私人字卡可透過 Entry ID 連結字典詞條，每日學習及正式複習的答案面可展開字典詳情。
- 使用者由字卡介面點選「字典」進入公共字典。
- 字典總覽頁頂部由左至右顯示「←返回字卡」、「字典」、「管理字典」。其中「管理字典」只對管理員顯示；角色說明不作為畫面文案。
- 頂部區域下方顯示分隔線，以及「查詢英文、中文」搜尋輸入框、「搜尋」按鈕、「篩選」按鈕。
- 「篩選」按鈕開啟浮動選單，包含「單字」、「字首」、「字根」三個可多選項目，預設全部選取。

#### 詞條詳情與操作
- 點選詞條卡片進入詳情頁，呈現義項、歷史詞源、構詞關聯、口訣及記憶故事。
- 詳情頁頂部提供「返回上頁」；管理員另外顯示「編輯此詞條」，可在詞條所在頁面直接編輯。
- 詳情頁提供上一筆、下一筆詞條導覽，手機和平板支援左右滑動切換。
- 返回時回到實際來源畫面，保留來源清單的搜尋、篩選與瀏覽上下文。
- 同一詞源的註釋內容集中在同一視覺容器中呈現。

#### 字典管理
- 管理員可匯入、新增、發布、管理、編輯及刪除公共字典詞條。
- 由「管理字典」進入的管理畫面，提供「新增」、「匯入」、「匯出」、「刪除」、「發布」、「全選」控制項。
- 「匯入」開啟浮動視窗，**管理介面此入口只接受 CSV 檔案**。
- 「新增」開啟共用的詞條新增面板，提供 Word／Prefix／Root 類型下拉選擇。
- 編輯已發布詞條時產生供審閱的 Draft／revision，管理員明確確認發布。
- 所有公開詞條的新增、編修、刪除及發布由系統驗證管理權限；讀者依已發布狀態查看內容。

#### 詞條內容
- 詞條類型：單字（Word）、字首（Prefix）、字根（Root）。
- 內容欄位：詞條、讀音、變體、種類、義項、口訣、記憶、詞源、構詞關聯。
- 建立詞條可先填入詞條基本資料，並可建立多個 Sense，分別記錄詞性、繁體中文義項，以及適用該義項的例句、讀音、詞源。
- 正常閱讀及編輯流程以義項內容呈現資料，由系統管理 Sense 身分及 UUID。
- 讀音可記錄 Entry 共用或 Sense 專用的 IPA 與 locale，同一詞條可有多筆讀音。
- Word 編輯介面包含基本詞條／分類、中文義項、構詞關聯、歷史詞源、口訣及記憶故事。
- 歷史詞源保留完整敘述及其內容來源；一般第三方資料來源與版權說明位於「設定 → 關於 Nexus → 資料來源與版權」。
- 匯入及修改流程維護 revision、交易回滾、權限、審計、資料完整性及跨裝置同步一致性。

#### 字首與字根分類
Prefix 共四類，主要分類設定於 Sense level，同一詞條家族的不同 Sense 可屬不同類別：

1. 性質、評價與否定
2. 位置、方向與關係
3. 數值、量與程度
4. 作用與變化

Root 共九類：

1. 空間、位置與環境
2. 動作、接觸與物理作用
3. 移動、轉變與方向
4. 物質、自然與元素
5. 生命、身體與感官
6. 情感、心理與意志
7. 心智、溝通與學習
8. 社會、法律與制度
9. 時間、狀態、數量與邏輯

Word 使用自身的詞條與義項分類方式。

#### 詞條識別、義項與匯入規則

- 同一詞條類型（Word／Prefix／Root）中，忽略英文大小寫及詞頭、詞尾空白後，相同拼寫對應同一 Entry；不同類型可以存在相同拼寫的詞條。
- 一個 Entry 可包含多個 Sense，依詞性、繁體中文義項、歷史詞源與語意差異區分；字卡連結採穩定的 Entry ID，編輯及匯入時保留 Entry／Sense 識別。
- 詞性、中文釋義及僅適用特定意思的讀音、例句、詞源和記憶內容，歸屬相應 Sense；整個詞條通用的資訊可由 Entry 共用，管理端能辨別兩者。
- 支援一個詞條具有多筆 IPA 讀音、語言／地區標記，以及 Entry 共用或 Sense 專屬的讀音。
- 匯入時，系統檢查重複詞條、義項對應、欄位與關聯有效性；無法確定的更新交由管理員審查，並保留其他義項內容。
- 匯入預覽提供可直接套用、需審查及無效資料的辨識結果；正式套用時重新核對資料版本、管理權限及衝突，並保留匯入紀錄與可安全重試能力。
- 詞形變化（例如 write／wrote／written）與構詞衍生（例如 act／action／active）屬不同關聯性質；細部呈現、編輯方式及匯入格式待核准。


### F-SCORE — 製譜

- **製譜（F-SCORE）**：作品管理、簡譜、五線譜與吉他譜的預覽及編輯工作流。

- **C2 已確認先前順序**：先作品管理＋快速簡譜，再各自開發五線譜與吉他譜；三者不強制互轉，也不預設共用同一完整音樂資料模型。正式譜面 preview 優先，進入「編輯」才顯示文字源碼；桌面可探索分割畫面，手機以預覽／編輯切換為主。
- **候選簡譜草案（未最終確認）**：`_6`／`^6` 表八度、`#5`／`b7` 升降、`6•` 附點、`5/`／`5//` 時值、`0` 休止、`|` 小節；標頭 `@title`／`@key`／`@time`／`@tempo`，註解 `//` 屬草案，不直接當 parser 合約。播放與完整 MusicXML／MIDI 互轉非首版承諾。

### F-PRESENTATION — 簡報

- **簡報（F-PRESENTATION）**：投影片畫布、物件移動與縮放、旋轉、圖層排序、圖表與投影片導覽。

- **資料方向**：Presentation → Slides → PresentationBlocks；block 使用 x/y/w/h%、z-index、rotation。PresentationBlock 新增 `rotation?: number`。ChartData 新增 `sortOrder?`、`showDataLabels?`、`showGrid?`、`showTitleNumber?`。
- **待細化能力**：對齊吸附、旋轉物件縮放、群組與鎖定、母片、圖表、復原與重做。

- **驗收**：畫布物件 reload/sync 後位置與內容正確，且真實瀏覽器互動通過。
- **畫布互動**：物件中心可拖曳移動，邊緣可調整大小；圖層可排序，圖表可調整顯示選項。

#### 物件操作與匯出

- 支援投影片、物件移動／縮放／旋轉、層級排序、圖表與投影片導覽；吸附、群組、鎖定、母片及匯出格式細節待核准。

#### 投影片預覽、縮圖與畫布閱覽
- 簡報工作區以目前選取的投影片為主要畫布，旁邊提供可收合的投影片縮圖列表；縮圖應預覽投影片內容及物件層次，而非只顯示標題。點選縮圖切換目前投影片，清除前一張投影片的物件選取狀態。
- 投影片清單提供新增、複製、刪除及選取操作；複製的投影片保留內容與排版但具有獨立識別，刪除不得在僅剩最後一張投影片時清空整份簡報。
- 縮圖、中央畫布與實際儲存內容應一致；移動、縮放、旋轉及調整圖層後，縮圖與畫布應更新，重新開啟仍能還原。
- 圖表的編輯區應能同時辨識圖表類型、設定、預覽及資料；修改圖表選項時，預覽應反映實際成品。圖表編輯是作品內容的操作，不等同整份簡報的播放／放映模式。
- 簡報另需明確區分「編輯畫布」、「無編輯控制項的預覽／放映」及「投影片縮圖」；**獨立全螢幕放映、鍵盤切換、手機手勢及播放控制等細節尚待核准，不應因程式碼未做便移除這類產品方向**。

- **資料**：隨手記是獨立內容類型，卡片可設定顏色，搜尋、備份與帳號同步涵蓋其內容。

### F-CREATIVE — Creative 入口

- **創作入口（F-CREATIVE）**：角色卡及世界觀等創作工具入口，小說有獨立入口。

- **資料方向**：Page shell + `kind: "creative"`；以 `creative_type` 區分 `novel`／`character`／`world`。
- **入口**：小說設有獨立功能入口；創作入口提供角色卡與世界觀，相關範本以「模板」命名。
- **判斷函式**（`types.ts`）：`isCreativeCharacterPage`＝creative 且（`character`／`world`／有 `character_data`）；`isNovelPage`＝creative 且非角色類。早期沒有 `creative_type` 的舊小說以此相容。

### F-NOVEL — 小說

- **小說（F-NOVEL）**：作品總覽、章節、閱讀模式及閱讀設定。

- **入口與總覽**：`creative_type: novel` 開啟時先進入作品總覽：封面（PNG／JPEG／WebP，≤ 3 MB，實際附件保存與同步）、可編輯作品名稱、獨立概述（`NovelSettings.synopsis`，不得由正文自動推導）、字數／章節統計、完整目錄。
- **內容邊界（D-201）**：只有段落、H1、H2 與基本 inline 文字樣式；貼上一律轉純文字；不含表格、圖片、清單、提示框、程式碼、LaTeX。
- **章節（D-209）**：
  - 章節是獨立的 `pages` 記錄：`kind: "novel_chapter"`、`parent_id`＝作品 ID、`sort_order`、標題、正文、建立／更新時間；繼承 `owner_id` RLS、同步、tombstone 與備份。
  - **啟用章節工作區時**才把舊單篇正文轉存為章節並清空作品正文；不啟用則不動舊資料（`NovelSettings.chaptersEnabled` 只由明確、交易式啟用寫入）。
  - 目錄、上一章／下一章、刪除、排序、重新命名皆操作獨立章節；重新命名與排序保留章節 ID。
  - **翻頁**：章與章之間透過**頂部與底部**的「上一章／選章／下一章」切換，不再把各章放在同一流動頁的前後區塊。
  - 章節頁不出現在一般頁面清單、Dashboard、右側面板、Command Palette（`NexusApp` 以 `kind !== "novel_chapter"` 過濾）。
  - 登入後預設選取項目時會排除章節（`novelChapters.ts` 的 preferred 邏輯）。
- **閱讀設定**：`NovelSettings.theme`（parchment／cream／eye_care／dark／pure_white）、`fontSize`（14–26）、`fontFamily`（serif／sans／kai）、`lineHeight`（1.6–2.4）、`paragraphIndent`、`showWordCount`。
- **手機**：目錄為覆蓋式面板；閱讀／編輯主區獨立垂直捲動。
- **驗收**：`tests/novelChapters.test.cjs`；隔離瀏覽器測試（桌面與 390×844）通過；正式帳號同步未測。

### F-CHARACTER — 角色卡

- **角色卡（F-CHARACTER）**：結構化區塊、混合內容、分頁及自訂模板。

- **資料真相**：`Page.character_data`（`CharacterProfileData`）；`basic`（姓名、別名、頭像、性別、年齡、角色、所屬、名言、自訂欄位）＋`sections[]`＋`tabs[]`。
- **區塊與內容（D-210）**：使用者可加「區塊」（`type: "group"`），區塊內可放多筆「內容」（`contents[]`），每筆內容有標題與一種資料類型。舊的單一類型區塊（葉節點）維持可讀可編輯。
- **資料類型（程式碼型別 `CharacterComponentType`）**：`group`、`key_value`、`rich_text`、`tags`、`stats`、`rating`、`relations`、`radar`、`palette`、`tendency`、`statistics`、`gallery`、`links`、`music`。對應使用者所稱的長文（`rich_text`，檢視時預設收合，可點三角形展開）、雷達圖（可新增細項，實際繪圖）、評分、偏向、統計、色票（可新增細項）、相冊、連結、音樂（只存外部連結）；「短文」與 `key_value` 的對應**未核實**。
- **統計**：每列有三格內容——短文字、長文字（多行介紹）、數值（可含單位）；欄位頂部有可自訂小標（`statisticHeaders`）；會把所有細項數值加總（測試例：37 + 5 = 42）。
- **分頁**：一張角卡可加多頁（類似試算表底部切換），用於補充資訊（例如 D&D 法術、攜帶物品）。原 `sections` 為「基本資料」分頁；分頁列位於底部；可新增、重新命名、排序、刪除（刪除有確認，取消不變動）。
- **外觀**：組件標題不使用 emoji（型別仍保留 `icon` 欄位但 UI 不顯示）。
- **模板（D-210）**：
  - 只在**建立時**詢問模板；建立後不再提供更換模板。
  - 內建：空白（完全無區塊、無填寫內容）、D&D 5e、CoC 7e（各自專用欄位與補充頁；只是記錄格式，**不是規則計算器**）；另保留 `fantasy`／`modern` 型別值供舊資料。
  - 使用者可自訂：按「將目前組件與內容設為模板與範文」存成模板；可在模板管理重新命名／管理。
  - **範文**（`example`、`basicExamples`）只以 placeholder 呈現，例如「破曉之刃」、「男」，**不會**填成角色資料；數值與視覺預設仍可編輯。
  - 自訂模板是帳號擁有的 creative 頁面，`character_data.isTemplate = true`，隨既有備份與同步；**更新模板不改動已建立的角色**。模板頁不出現在一般頁面清單。
  - 從模板建立時複製區塊與分頁結構並產生新 ID（`instantiateCharacterTemplate`）。
- **驗收**：`tests/characterWorkspace.test.cjs`；隔離瀏覽器：混合區塊、統計加總、長文收合、分頁管理、存模板／建角色、重新載入保留。

#### 角色卡範本及資產

- 可為角色卡儲存及套用模板；模板更新保留既有角色資料。
- 頭像及相簿附件與角色資料建立關聯。

#### 角色卡閱覽畫面與欄位呈現
- 角色卡區分「編輯表單」與「角色卡閱覽」兩種模式。編輯模式提供輸入、刪除、增減內容、區塊與分頁管理；閱覽模式應將已填寫資料呈現成可閱讀的角色檔案，不展示只用於編輯的操作按鈕與輸入控制項。
- 基本資料區可呈現姓名、別名、頭像、性別、年齡、角色、所屬、名言及自訂欄位；自訂欄位以使用者設定的名稱／內容顯示，並與內建欄位並存。
- 內容以具標題的區塊組織，區塊可包含多筆不同型態的內容；支援單欄或雙欄呈現，窄螢幕回落單欄。長文在閱覽時可展開／收合，且應保留段落換行。
- 角色卡的各補充分頁可在頁面底部切換；切換只改變目前閱覽的資料群組，不改寫其他分頁內容。角色資料、區塊及補充頁在重新開啟後須保留。
- 雷達圖至少有三個維度才繪製；每個維度顯示名稱、數值與上限。統計類內容依欄位顯示項目、文字介紹、數量、單位重量及總重，並呈現總數量、總重量；詳細欄名及顯示格式可以再核准，不應只顯示原始 JSON。
- 評分、偏向、色票、相簿、角色關係及外部連結等內容，各自使用適合閱讀的視覺方式；閱覽模式中的數值及資料不得因切換模式而更動。現有偏向尺度採中點 50，編輯時靠近中點可吸附；是否固定作為產品規則尚待核准。
- 編輯／閱覽的控制項位置、空欄位隱藏方式、手機閱覽排列及模板範文是否顯示，需再依使用者確認，不將現行元件的偶然樣式升格成永久規格。

### F-WORLD — 世界觀

- **世界觀（F-WORLD）**：結構化世界觀資料，角色可歸屬世界觀或獨立建立。

- **規格**：`creative_type: "world"`，沿用角卡的區塊／內容／分頁／模板機制，可進行設定與描寫。
- **歸屬**：角色以 `character_data.world_id` 歸屬某世界觀，或為空表示獨立角色。
- **邊界**：世界觀／人物／地點與**小說**的關聯明確不做（D-201）。
- **待確認**：使用者原話為「類似角卡，也可以進行設定與描寫」；現況是否已足夠、是否需要世界觀專用內建模板，尚無明確要求。

### F-UTILITY — 網頁／計數／抽選

- **網頁收藏（F-WEB）**：介紹資訊與連結清單編輯；公開展示另行設計。
- **計數（F-COUNTER）**：項目計數、依群組名稱彙總；階層群組設計待確認。
- **抽選（F-DRAW）**：項目庫、標籤篩選與抽選指定數量。

三者共用 `UtilityView`，資料存在 `Page.content_json`（D-218），皆為**基礎版**。

- **網頁（F-WEB）**：`intro`（介紹）＋`links[]`（`{id, label, url}`）。使用者要求「類似 lit.link」：**對外展示頁、版面設計、公開網址均未做**（依賴 M8-0／M8-1）。
- **計數（F-COUNTER）**：`counters[]`（`{id, name, value, group?}`）。「大組」以文字欄 `group` 表示，介面依名稱加總並顯示各組合計與全部合計；空的 group 顯示「未分組」。使用者原意是「一個計數項目可分大組與小組，大組是小組總和，小組可單獨存在」——**正式的大組物件與階層 UI 尚待資料模型確認**（M10-8）。
- **抽選（F-DRAW）**：`draws[]`（`{id, label, tags[]}`）；一個抽選項目 = 一個資料庫；單筆可多標籤（逗號分隔輸入）；抽取時勾選標籤，候選為**同時具備所有勾選標籤**者，再隨機抽指定數量。使用者要求的「某標籤抽幾個」「標籤配標籤」等規則**尚未做**（M10-9）。
- **新增選單**：三個功能各有對應新增項（網頁／計數項目／抽選資料庫）。

#### 收藏、計數與抽選擴充

- 網頁收藏可整理介紹與連結清單，公開展示頁的網址、權限和版型待核准。
- 計數可依群組名稱彙總數值；大組／小組層級與調整方式待核准。
- 抽選可依標籤篩選並選取指定數量；各標籤分別抽 N 個、標籤組合與去重規則待核准。

### F-EDITOR — Editor Blocks 與內容插入

- **視覺畫布（F-CANVAS）**：以 Page／Block 引用組織視覺化內容。

| --- | --- |
| Paragraph、Heading、Bullet／Ordered List、Quote、Code | 基礎 Tiptap content；保存於 `content_json` |
| Link、TaskList | 真實 node／mark；編輯模式下 link 不自動跳轉 |

#### 文字操作、表格與浮動選單

- 編輯器與表格提供全選、複製、貼上及剪下；一般文字輸入框使用系統文字操作選單。
- 浮動工具選單保持在視窗可見範圍；表格編輯選項由表格右鍵／情境選單開啟，可對選取儲存格執行平均欄寬等操作。
- 自訂貼上支援純文字與 HTML；圖片可透過支援的編輯器系統貼上或插入。
- Table、Presentation canvas 與觸控裝置上的編輯手勢及詳細工具尺寸待定。

#### 插入與資產管理

- 圖片可由支援的編輯器插入，提供替代文字與尺寸調整；內容附件與媒體資產庫的分類、引用及保存細節待核准。

#### 筆記通用題目工具

- 插入內容選單提供題目／自動題號、選項、答案／解析與作答空間等工具，與一般段落、表格及數學式共同使用。
- 題目與選項提供增刪、編輯、重新排序及相應的自動標號；設定項與操作細節依 `F-NOTE`。
- 這些工具屬於筆記的通用內容編輯功能，不以「講義」作為使用前提。

### F-PAGEFORMAT — Flow、A4 與簡報格式

- **Flow**：Note 預設流動內容；流動格式不被自動改成分頁。
- **A4**：固定 A4 210mm × 297mm；自動分頁、內文可寫到底部、頁碼置中顯示。
- **Presentation**：16:9／4:3 由 Presentation 使用；Note 不應因此被當作簡報。
- **Document**：偏 A4；可依既有格式規則選擇 flow／A4／custom。
- **Custom**：⚠️ 有型別預留，但尺寸、行為與列印規格尚未形成完整 contract。
- **已知限制**：目前自動分頁仍有估算高度啟發式；表格、圖片、複雜內容需未來 DOM measurement 改善。

### F-NAVIGATION — Home、Sidebar、File Menu、Dual Pane

- **網站發布（F-WEBSITE）**：分享頁面、連結頁及網站發布流程。
- **唯讀分享（F-SHARE）**：可控的唯讀連結、存取與撤回管理。

- Home 是預設入口；Nexus logo 可回 Home。
- Sidebar 支援 folders、favorites、sort、type grouping、drag/drop、同類子頁、rename、bulk select。
- 子頁規則：同類型可成子頁；Presentation 不可成子頁；深度限制依現行 Sidebar 規則。
- File Menu 在工具列最左，承擔新建、匯入、格式、轉簡報、頁面管理、匯出／列印。
- Ctrl+點擊可開啟右側 Dual Pane；可 swap／close secondary pane。
- **功能兩欄格【新增，D-207】**：左側功能以**兩個一橫排、豎排最多四列可見**顯示。第一列固定「全部項目」與「日曆」；其餘功能（筆記、文檔、簡報、字卡、隨手記、創作、小說、網頁、計數、抽選）預設依**最新使用**重新排列。單擊功能變更篩選、雙擊才開啟（原 01 §14.1 已歸檔至 02）。
- **排序模式**：`recent`（預設，最新使用）／`default`（固定順序）／`custom`（自訂）。`recordFeatureUsage` 不記錄 `all` 與 `calendar`。偏好存在瀏覽器 localStorage（`nexus-feature-order-mode`、`nexus-recent-features`、`nexus-custom-feature-order`），**屬裝置本機偏好，不隨帳號同步**。設定入口在「詳細設定 → 功能排序」。
- **新增選單隨功能切換【新增，D-208】**（`creationOptions.ts`）：全部項目→筆記／文檔／字卡集／簡報／角色卡／世界觀／小說／網頁／計數／抽選／資料夾；筆記→流動筆記／分頁筆記；創作→世界觀／角色卡；小說→小說作品；文檔→文檔；簡報→簡報；字卡→字卡集；日曆→日曆事項；隨手記→隨手記；網頁→網頁；計數→計數項目；抽選→抽選資料庫。
- **首頁與清單捲動**：首頁在檔案數量多時曾無法上下滑動，已調整捲動容器與高度限制，**待大量檔案與實機驗證**。
- **新註冊帳號**：註冊後進入專屬空白工作區，可自行建立第一份內容。
- **手機**：側欄／輔助欄以浮層開啟、不擠壓編輯器，有遮罩；手機寬度下左側面板預設收合為零寬（原 01 §14.1，見 02 存檔）。使用者要求「開啟時不能編輯、點擊編輯器後兩欄自動收回」——浮層與遮罩已有，**鍵盤焦點完整禁用與點背景收合仍待驗收**。平板輔助頁的開合鍵位置已調整（原被右上角帳號擋住；右上角帳號入口之後已移除），待不同寬度實機檢查。

#### 首頁、工作區導覽與系統檢視

- 開啟 Nexus 後進入 Home／Dashboard，顯示統計、最近編輯及功能快速入口；點選 Nexus Logo 返回首頁。
- 側邊欄提供 Projects／Folders 分組、排序、拖曳移動、子頁、我的最愛、重新命名及多選。
- 搜尋支援標題與內文，並能依內容類型篩選；Command Palette 可搜尋頁面與執行命令。
- Inbox／Quick Capture 可快速建立收集項目並保留目前編輯狀態。
- 回收桶提供項目查看、還原、永久刪除及批次操作；右側面板顯示反向與外向連結。
- File Menu 提供新建、匯入、格式、頁面操作、匯出及列印。
- 手機下側欄以浮層與遮罩呈現，側欄按鈕放在編輯器頂部左側；側欄開啟時焦點留在浮層，返回編輯區後收起。
- 螢幕可用寬度不足時，Sidebar／輔助欄使用覆蓋式面板，保留主要編輯區可用空間。
- Home 與功能總覽清單在捲動頂端支援下拉刷新：由清單頂部 80px 內起始，24px 緩衝、0.35 倍阻力、80px 指示距離及至少 500ms，放手後刷新；先完成待儲存資料保存。
