# Nexus 正式產品規格（工作基線）

> 狀態：初步整理，2026-10-12。此文件記錄目前已知的**產品決策**，不是整個 Nexus 所有模組的完整規格，也不代表每項功能均已實作。需要從既有交接檔逐項補齊；不要將缺漏視為功能取消。

## 1. 平台定位
Nexus 是整合學習、知識與創作工具的模組化 Web 平台。模組需遵守一致的帳號資料隔離、權限、基本互動與可維護性原則。具體完成狀態見 `HANDOFF.md`，技術實作見 `ARCHITECTURE.md`。

## 2. 語言學習：公共字典與私人單字卡
- 全站共用**一套公共字典**，內容集中管理；一般使用者可閱讀，管理員才可增修公共資料。
- 使用者建立、擁有、管理自己的**私人單字卡**，並可連結公共字典的詞條顯示補充內容；公共字典不是每位使用者各自維護的私人百科。
- 字典內容支援 Word、Prefix、Root 等類型；同一詞條可以有多個 Sense，不把每種詞義當成互不相關的 Entry。
- 單字卡複習規劃使用 FSRS；複習、測驗進度應屬個人資料。

## 3. 公共字典操作
- 「新增」使用統一的編輯面板，透過下拉選項設定 Word / Prefix / Root。
- 「匯入」與「新增」同級，按下才開啟獨立浮動視窗。
- 詞條詳情可前後切換；手機、平板可左右滑動。
- 詞條詳情頁不必另外放「回到全部單字」按鈕；返回應回到實際來源頁。
- 管理員可在詞條詳情頁由右上方直接開啟編輯。
- 同一來源的註釋內容應整合在一個區塊顯示，減少過度分框。
- 預期用戶介面權限與實際寫入權限一致；後端需獨立驗證權限（詳見技術文件）。

## 4. 字典資料編輯與匯入
- 手動新增、JSON 匯入與 AI 內容均應通過共用的草稿驗證流程；必須保留需要人工審核的資訊。
- 區分可安全匯入（Safe）、需人工確認（Review）與無效（Invalid）；不得靜默覆寫既有詞義或來源。
- 匯入前應檢查重複 Entry、Sense、來源相容性與既有資料衝突。
- 批次匯入的具體數量與正式環境狀態須從資料包、驗證報告及部署紀錄核實，不以計畫值代替完成值。

## 5. 其他模組
現有程式碼及開發紀錄涉及筆記／創作、簡報、PDF 工作區、樂譜、行事曆等方向。此處尚未完成各模組正式行為規格的遷移；不能將本節當作功能已上線清單。

## 6. 規格維護
新產品決策更新本文件；技術細節放在 `ARCHITECTURE.md`。過去方案及改動理由保留在 `HISTORY.md`；待實作的工作以 GitHub Issues 追蹤。


## 帳號刪除：使用者行為
- 使用者入口：側欄「帳號」→「刪除帳號」→ 輸入「刪除帳號」→「永久刪除」。
- 必須確認目前使用者的電子郵件與指定確認文字，才可刪除自己的帳號；不得指定或刪除其他使用者。
- 帳號及其私人筆記、附件、Study、Quiz、已安裝之舊字源資料，依現有資料模型安全刪除；不應連帶清除他人資料或共用舊資料。
- 成功後登出、清理目前帳號的本地離線快取與附件二進位快取，返回首頁；其他帳號資料與一般偏好保留。
- 伺服器端功能尚未啟用時顯示明確提示；如果連線中斷致結果不明，要求重新登入確認，不能先宣稱刪除成功或清除本地資料。
- 其他裝置已保留的離線副本無法由此流程遠端抹除；不得宣稱所有裝置上的副本皆已清理。


## 7. 核心工作區與資料原則（由 2026-10-11 Canonical Spec 整理）
- Nexus 是 **local-first 個人學習與知識生成 workspace**，不是完整 Notion／Canva／Wix 複製品或企業共編服務。登入是必須的：未登入只顯示登入／註冊；登入後才讀取該帳號本地快取與同步資料，無匿名私人工作區；共編不在目前範圍。
- 核心概念：Page、Block、Property、Workspace View、Page Mode。頁面共用 Page shell，依 kind 使用 mode-specific data。生成物可記錄來源，但不要求來源變更後自動覆寫。
- **Note**：原生富文字筆記優先，正文以 JSON 保真；匯出以 Print/PDF、Nexus JSON 為主，不能宣稱 Markdown 完整往返保真。**Document**：獨立於 Note，偏純文字／Markdown，支援 Markdown 匯出。Note 預設流動版面；A4 210×297mm 與簡報版面各有不同用途。
- **PDF**：當前基本工作流為 PDF 匯入、attachment 與 Research Note 關聯；未來 GoodNotes-like PDF workspace 須先決定註釋、頁面及引用契約，不預設已完成手寫或 PDF 頁面管理。
- **Editor／講義**：支援表格、Callout、數學公式、TaskList、Link 等內容區塊；講義包含樣式、頁首尾、目錄、例題／練習／解答、作答留白、編號與 A4 整理分頁。分頁整理須使用者主動觸發，可撤銷且不能破壞手動分頁；教師／學生版 PDF 已明確排除。Image 以插入內容為主，不另外定義成一般獨立 Page 種類；Audio／Video 暫不納入。
- **導覽／偏好**：Home、Sidebar、搜尋、Inbox、Trash、Backlinks、Command Palette 與兩欄功能入口分工明確；功能排序 recent/default/custom，偏好第一層為主題、語言、設定、備份。帳號入口位於側欄。行動裝置側欄採浮層與遮罩，鍵盤焦點與點背景收合等仍需實機驗證。
- **分享**：個人唯讀分享連結是獨立規劃，不能靠公開私人資料的 RLS 實現；權限、匿名存取、撤權、附件等細節仍待產品決策。網站發布另為後續功能。

## 8. Study Set／FSRS 與測驗正式契約（需按現行程式碼核對）
- Deck 為 Page，Card、排程狀態、歷史事件、設定是使用者獨立資料；與公共詞條的連結只提供補充，不覆寫英文／中文內容或 FSRS。
- 計畫演算法：FSRS-6（原 Canon 指定 `ts-fsrs 5.4.2`）、request retention 0.90、learning/relearning steps 10m、fuzz 關閉；排程和事件需保留歷史及參數。
- 每日新字練習：英→中主動回想，預設每組 20 張（可調），當日批次持久化；Easy 才算完成新卡引入，不能把首次引入偽裝成正式複習事件。
- 正式複習：持久化 session，預設 20 張，New → Due → Not-due 補位；每張每輪首次評分才寫正式 FSRS 事件，Again／Hard 重排、Good／Easy 出箱；後續重練只改 session 熟練度。
- 四選一：預設中→英，可切換；至少四個相異選項，題目權重考慮記憶狀態與錯題分數；測驗不修改 FSRS。離線結果由使用者決定上傳／捨棄／稍後，重送須冪等。
- 遷移舊卡不得把舊 `review_count`／`daily_phase` 當成 FSRS 真實歷史；英文修改需提供保留排程／重設／取消，中文修改保留排程，複製內容不繼承排程。
- Study 字卡列表採 English A–Z 兩欄預覽與點整列編輯；每日學習／正式複習背面可展開公共字典詳情，評分按鈕 → 詳情 → 詳情末端儲存提示；詳情讀取不產生 FSRS 事件。
- 多裝置離線同卡衝突不可自動丟掉事件或靜默套用；需顯示衝突並要求明確恢復決策。正式端到端驗收不能由本機測試推論。

## 9. 字典內容治理補充
- 管理員應依 Google OAuth 對應的可信 Auth UUID 或後端管理角色授權；不能只看前端按鈕或 email。一般登入者只讀已發布詞條，Draft 與 Published 有明確區分。
- 同形異源及歷史詞源與教學拆解要分開；構詞關係需要 sense-level 證據，未核對的資料不可冒充 verified。
- 2026-10-11 Canon 提出正式母檔基準 **6,301 Entries／6,304 Senses**（Word 6,163、Prefix 79／82 Senses、Root 59），並要求 13 份 canonical CSV 逐份 Preview → Safe／Review／Invalid → Apply Safe → 人工審核 Review。這是匯入契約／計畫數量，不代表 production 已匯入。
- 正式相容規則包括唯一 Entry identity、Sense-specific 內容與發音、詞形變化與派生分離；沒有人工核可不得把相似詞源自動合併。
- 新的來源／授權策略已取代舊一般 `source/license` 欄位；需獨立資料來源與版權頁，並保留舊資料格式相容處理。**不新增 Import Batch ID**；使用既有 operation receipt／audit。
- 既有字卡不因公共詞條下架／編輯而遭刪除；連結失效需要可理解的降級顯示。

## 10. 其他創作與個人工具規格
- **Presentation**：Slides／Blocks 自由畫布，物件拖曳、縮放、旋轉、對齊、縮圖鏡像與圖表編輯；吸附線、旋轉後縮放、群組、鎖定、Slide Master、undo/redo 等需再驗收／開發，不承諾完整 Canva。
- **Quick Notes／Todo**：各是統一 pages kind，不另建獨立 local store；Todo 現有月曆基線，多分類日曆屬 Discovery。
- **多分類日曆（未決）**：特殊日、排班、記帳、日記1、日記2、要事、Todo，可同時或單獨顯示、可自訂類別；分類模型和專屬欄位尚未核可，不能直接實作。
- **Novel**：獨立作品總覽、封面、概述、章節、閱讀設定；編輯僅允許受限文字格式，不含表格、圖片等富內容。小說與世界觀／人物／地點自動關聯已明確取消。
- **Character／World**：區塊下含多種內容類型、分頁、模板；世界觀可擁有角色歸屬，角色也可獨立，與小說不強制關聯。
- **Web**：介紹與連結列表基線；對外展示頁尚未開發。**Counter**：目前依群組名稱合計，大組／小組正式階層模型待決。**Draw**：多標籤交集篩選後抽取 N 個，各標籤配額與配對規則未完成。
- **Score（製譜）**：先作品管理與簡譜，後續五線譜／吉他譜；輸入語法仍是草案，指令已發不等於功能完成。
- **Canvas**、公開 Website／Publish Project、閱讀資產庫等仍為未來工作，不能列成現行已上線能力。

## 11. 互動與驗收邊界
- 一般頁面刪除採 Trash 軟刪除與恢復；永久刪除限 Trash 操作。清除頁面不能無條件連帶清除可能共用附件。
- 下拉刷新限定首頁／清單且需在頂部放手才刷新，先等待正在進行的儲存；禁止干擾文字選取或編輯。編輯器右鍵、表格操作需維持剪貼簿功能；小說貼上轉純文字。
- 實作驗收要分清「程式碼存在」「本機測試」「部署前端」「production migration 已套用」「正式帳號與實機驗收」；不能混用完成標籤。
