# Nexus 正式產品規格（工作基線）

> 狀態：初步整理，2026-10-12。此文件記錄目前已知的**產品決策**，不是整個 Nexus 所有模組的完整規格，也不代表每項功能均已實作。需要從既有交接檔逐項補齊；不要將缺漏視為功能取消。

## 1. 平台定位
Nexus 是整合學習、知識與創作工具的模組化 Web 平台。模組需遵守一致的帳號資料隔離、權限、基本互動與可維護性原則。具體完成狀態見 `HANDOFF.md`，技術實作見 `ARCHITECTURE.md`。

## 2. 語言學習：公共字典與私人單字卡
- 全站共用**一套公共字典**，內容集中管理；一般使用者可閱讀，管理員才可增修公共資料。
- 使用者建立、擁有、管理自己的**私人單字卡**，並可連結公共字典的詞條顯示補充內容；公共字典不是每位使用者各自維護的私人百科。
- 字典內容支援 Word、Prefix、Root 等類型；同一詞條可以有多個 Sense，不把每種詞義當成互不相關的 Entry。
- 單字卡複習規劃使用 FSRS；複習、測驗進度應屬個人資料。

## 3. 公共字典操作
- 「新增」使用統一的編輯面板，透過下拉選項設定 Word / Prefix / Root。
- 「匯入」與「新增」同級，按下才開啟獨立浮動視窗。
- 詞條詳情可前後切換；手機、平板可左右滑動。
- 詞條詳情頁不必另外放「回到全部單字」按鈕；返回應回到實際來源頁。
- 管理員可在詞條詳情頁由右上方直接開啟編輯。
- 同一來源的註釋內容應整合在一個區塊顯示，減少過度分框。
- 預期用戶介面權限與實際寫入權限一致；後端需獨立驗證權限（詳見技術文件）。

## 4. 字典資料編輯與匯入
- 手動新增、JSON 匯入與 AI 內容均應通過共用的草稿驗證流程；必須保留需要人工審核的資訊。
- 區分可安全匯入（Safe）、需人工確認（Review）與無效（Invalid）；不得靜默覆寫既有詞義或來源。
- 匯入前應檢查重複 Entry、Sense、來源相容性與既有資料衝突。
- 批次匯入的具體數量與正式環境狀態須從資料包、驗證報告及部署紀錄核實，不以計畫值代替完成值。

## 5. 其他模組
現有程式碼及開發紀錄涉及筆記／創作、簡報、PDF 工作區、樂譜、行事曆等方向。此處尚未完成各模組正式行為規格的遷移；不能將本節當作功能已上線清單。

## 6. 規格維護
新產品決策更新本文件；技術細節放在 `ARCHITECTURE.md`。過去方案及改動理由保留在 `HISTORY.md`；待實作的工作以 GitHub Issues 追蹤。


## 帳號刪除：使用者行為
- 使用者入口：側欄「帳號」→「刪除帳號」→ 輸入「刪除帳號」→「永久刪除」。
- 必須確認目前使用者的電子郵件與指定確認文字，才可刪除自己的帳號；不得指定或刪除其他使用者。
- 帳號及其私人筆記、附件、Study、Quiz、已安裝之舊字源資料，依現有資料模型安全刪除；不應連帶清除他人資料或共用舊資料。
- 成功後登出、清理目前帳號的本地離線快取與附件二進位快取，返回首頁；其他帳號資料與一般偏好保留。
- 伺服器端功能尚未啟用時顯示明確提示；如果連線中斷致結果不明，要求重新登入確認，不能先宣稱刪除成功或清除本地資料。
- 其他裝置已保留的離線副本無法由此流程遠端抹除；不得宣稱所有裝置上的副本皆已清理。
