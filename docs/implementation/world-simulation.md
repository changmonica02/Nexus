# Nexus 世界推演改良

## 本輪範圍

依使用者 2026-11-20 的指示，直接更新現行生成機制；不建立舊地圖遷移、舊演算法保留或雙版本切換流程。基礎網格、高度圖、海岸線與河流外觀的完整比較留到下一步，本輪沒有更換固定 36,002 格球面 Grid。

實際參考 planet-simulation 提交 `d09634e7306c5859d0aafa4afe3a090b641e31bc`：

- [planet.js](https://github.com/yuuranku/planet-simulation/blob/d09634e7306c5859d0aafa4afe3a090b641e31bc/site/core/planet.js)：大陸分組、面積份額、陸緣與遠洋島群。
- [climate.js](https://github.com/yuuranku/planet-simulation/blob/d09634e7306c5859d0aafa4afe3a090b641e31bc/site/core/climate.js)：西側邊界暖流、東側冷流、海陸熱差與海溫影響。

Nexus 維持文件要求的「已確認陸地與主要地形 → 板塊／地殼 → 海底 → 洋流 → 十二個月氣候 → 水文與生態」。沒有改成先推板塊再覆寫已確認陸地。

## 實作

| 部分 | 原處理 | 新處理 |
| --- | --- | --- |
| 大陸尺寸 | 各核心在窄範圍隨機指定半徑，再統一縮放 | 依大陸分組與種子分配不均等的球面面積份額，再換算球冠半徑；超大核心上限的剩餘面積重新分配 |
| 島群配置 | 隨機選海岸後在海格上隨機行走，方向任意 | 從陸緣法向向外放置，長軸沿海岸方向，檢查中心仍在海上並避免重複配置；保留少量遠洋島群 |
| 洋流驅動 | 年平均風帶與簡化科氏偏轉 | 加上依海岸方位、沿海距離與緯度控制的邊界流：副熱帶西側較強向極、東側較寬緩向赤道，副極地反轉 |
| 洋流連通 | 海格鄰接圖上的散度修正 | 納入雙格交界寬度與中心距離的有限體積通量，進行加權壓力投影；不穿陸地、不以海溝深度驅動表層流 |
| 海溫輸送 | 鄰格固定權重混合，受網格大小影響 | 沿邊成對交換熱量，使用格面積、交界寬度、物理距離與流速；以 CFL 條件控制時間步，加入水平混合及海氣回復 |
| 生成成本 | 預覽及確認各自重做初始陸地 | 同種子與設定直接消耗 Worker 中已計算的陸地預覽；修改設定後替換暫存，不保留多份候選 |
| 操作回饋 | 單一準備中訊息 | 實際回報大陸、地形、板塊、海底、島鏈、洋流、逐月氣候、水文、生態與顯示階段；生成器另顯示儲存階段 |

大陸與初始島群仍使用目前的地形模板產生局部形狀，本輪未消除模板建置對 Azgaar 的依賴。新增的配置、洋流、海溫與進度程式由 Nexus 自行維護。

## 主要模組

- `src/features/worldMap/core/worldLayout.mjs`：大陸面積與島群配置。
- `src/features/worldMap/core/surfaceOcean.mjs`：球面表層環流、邊界流與通量投影。
- `src/features/worldMap/core/oceanHeat.mjs`：保守海溫輸送與熱量收支診斷。
- `src/features/worldMap/globalMapProgress.ts`：進度契約及介面文字。
- `experiments/spherical-grid/natural-land.mjs`、`natural-planet.mjs`、`monthly-climate.mjs`：串接現行生成流程。

現行氣候識別更新為 2；生產 Worker 移除舊板塊演算法分流。版本欄位只用來偵測頁面與 Worker 不一致，不提供舊生成機制相容路徑。工作階段內的高度快照、儲存與手動重算仍保留，作為編輯功能本身的必要狀態。

## 驗證與解讀

理想化海盆測試中，20～40° 緯度範圍的西側海溫異常約 +1.9°C、東側約 −2.0°C，南北半球流向相反但暖／寒效果一致。以 12、24、36 級細分比較，暖／寒區差異接近，不再依賴固定的鄰格混合權重。

檢查項目包含：

- 固定種子重現、大陸份額總和、半徑與球冠面積一致。
- 島群中心位於海域、陸緣定位及群組最小間距。
- 洋流不穿陸地、球面切向、散度殘差及完全陸地／完全海洋的有限結果。
- 無海氣回復時的總熱量守恆、有回復時的熱量收支、CFL 上限、溫度範圍及解析度敏感性。
- 完整生成與預覽確認、編輯、儲存重開，以及逐階段進度不會提前完成請求。

這是簡化、參數化的自然環境推導，沒有宣稱為完整海洋動力模式或已通過真實地球校驗。數值與流程測試通過，也不等於地圖外觀已達到 planet 或 Azgaar 的自然度；後續須另比較高度圖、海岸、網格與河網。
