# 地圖總覽、圖層及河道向量編輯

## 介面與單一地表

- 移除編輯器頂欄的新增地圖入口。缺少地圖時才可建立唯一的地表；儲存層拒絕再次新增或建立巢狀 Nexus 地表。
- 更多操作左側新增圓圈驚嘆號，開啟原生對話框：陸地比例、球面陸海面積、24 小時一天、河湖數量。人口與國家尚無正式資料，以「尚未推演」呈現。
- 移除編輯器、畫布及生成預覽的重複陸地提示，以及編輯器操作提示。更多操作支援點擊外部、Escape 和執行操作後關閉。
- 疊加圖層使用雙欄、圓形滑塊開關。地形採自然地形配色，高度圖保留獨立海拔色階。氣候圖例顯示完整繁體中文與英文名稱，模型仍保留穩定氣候代碼。

## 水文與編輯

- 集水面積下限改為 24,000 km² 或平均陸格面積的五倍，起始年均流量至少 8 m³/s；限制源頭數量，六輪修剪弱短支流及沿海短段，修剪後重新連至河湖或海洋。
- 顯示篩選會遞迴保留可見支流的下游主河，避免主河隱藏後留下看似孤立的河段。
- 既有河道不因載入而重抽。工具提供「重新生成河網」，明確取代河道與名稱，保留湖泊範圍、水位及身分，重建入／出水關係。
- 選擇河流會定位及放大，控制點可拖曳；點線段新增、雙擊或 Delete 刪除，至少保留兩點。水平環繞與縮放使用同一投影。湖泊／支流關聯端點鎖定，主河共享匯流控制點移動時更新支流端點。
- 修改先預覽，套用後通過既有自然地理驗證、Worker、草稿及正式儲存流程。無法路由或成環時保留草稿並回報原因；取消還原畫面。

## 生態推演

維持 IUCN 第二層分類，加入生長季需水與供水、乾季月數、年缺水比例、低雨量寒冷荒漠與短生長季；濕地須同時具有長期土壤飽和、低起伏、局部集水地勢及鄰近河湖。修正高溫蒸散公式外插成負值的問題，避免極熱地區被誤判為無蒸散需求。

## PR #223 自動化測試修正

- 補登先前漏列的六份地圖測試，保留清單完整性檢查與既有測試範圍。
- 修正兩條沿用 Pack 網格的更新路徑，統一使用 Float32 高度；既有等價重建測試加入未編輯的 20.37 高度，驗證小數精度不會在更新時被截斷。
- 重現 Worker 重開測試的真正差異：海岸細節使用可改變的來源種子，讓相同儲存地形產生不同岸線。改為使用快照保存的海洋參照，來源種子更動不再改寫岸線。
- Worker 原本的記憶體耗盡發生在巨量座標的斷言差異輸出；改為逐欄位比對完整序列化內容的 SHA-256，仍驗證完整繪圖內容且可指出改變的欄位，沒有略過或放寬一致性要求。
